## 1. 结论摘要

当前问题不是“进入建议区就显示优秀”，而是系统曾把两个不同事实混在了一起：

1. 某个指标、旧支撑压力或宽区间只是原始候选参考；
2. 该区域已经通过方向、行情状态和周期权限校验，成为真正的建议入场区。

现行v8逻辑在部分路径中只满足第1项，就可能把位置评为 `IN_VALID_ZONE` 或 `STRUCTURAL_ADVANTAGE`，再与此前已经形成的触发分组合，恢复成可开仓动作。这会把“正在向下穿越一个宽区间”误判成“回踩后的优秀多头位置”。

v5.0确定以下原则：

- **进入未经授权的原始候选区不等于位置优秀；当前价格进入已授权建议入场区时，仍立即判定为“优秀”。**
- 普通趋势、通道行情和震荡行情的建议入场位置必须以1小时/4小时EMA20或EMA60独立区域为锚点；支撑压力、通道边界、BOLL、VWAP只能提供结构背景或与EMA形成共振，不能单独评为优秀并授权开仓。
- 15分钟EMA20/EMA60只允许服务于已经确认的强单边上涨/强单边下跌，不得成为普通趋势或震荡行情的替代主入场区。
- “突破回踩”建议区必须来自已经确认的突破/回踩事件，不能把旧压力区直接改名成突破回踩区；区域一旦合格，实时价格命中仍按现有规则立即显示优秀。
- 趋势推进、参与流和高总分只能说明行情值得关注，不能绕过位置与触发门槛。
- 普通初始止损按入场所属的1小时/4小时实体收盘结构失效执行；ATR只作为结构外缓冲，不再单独构成普通长线离场理由。
- 保留独立的远端灾难保护，但不得继续用普通结构止损价充当逐笔即时灾难止损。

## 2. 需求说明

### 2.1 改动背景

`1000RATS/USDT` 交易数据：

```text
方向：多
杠杆：5x
开仓价：0.0736926
建议区：0.0735699 - 0.0779901
止损价：0.07265
实际平仓价：0.07241
开仓时间：2026-08-03 12:55:57
平仓时间：2026-08-03 12:57:28
退出原因：ATR波动硬止损
```

从图形和交易记录看：

- 价格此前已从约 `0.05201` 快速上行至 `0.07760`；
- 开仓价已明显远离15分钟EMA21/BOLL中轨，更没有回到1小时或4小时EMA20/EMA60附近；
- 所谓“前压力突破后回踩确认区”宽约5.8%，区间过宽，不能表达一个精确的角色互换位；
- 开仓时进入的是未经高周期EMA授权的旧压力宽区，而不是合格建议入场区；
- 结构止损距离开仓约1.41%，小于图中单根15分钟K线约4.57%的振幅；
- 系统按实时标记价优先执行硬止损，91秒内离场，1小时/4小时结构确认没有获得执行机会。

因此本案例暴露的是一条完整错误链：

```text
宽泛候选区被命名为突破回踩
    → 实时价格进入这个错误区间即获得高位置分
    → 旧触发与当前价格状态没有事件一致性校验
    → 急涨后的回落被判为优秀入场
    → 普通结构价又被逐笔硬止损执行
    → 正常短期波动导致快速小额亏损
```

### 2.2 当前实现的核心缺口

1. `location_for_selected_level_v8()` 的“命中合格建议区给15或20分”本身保留；缺口在于调用前没有过滤建议区来源，导致不合格区域也能进入该函数。
2. `_select_location()` 优先选择当前命中的“结构区”，但 `breakout_retest` 被列为结构区后，没有再次验证它是否真的完成突破回踩事件。
3. `_entry_level_context()` 直接把1小时/4小时旧压力区映射成多头 `breakout_retest`，把旧支撑区映射成空头 `breakdown_retest`。
4. 项目已有较严格的1小时“前一根收盘突破、后一根回踩并收回”判定，但候选区构建没有消费这个结果，导致正确的触发事实没有约束 `breakout_retest` 的命名与授权。
5. v8 `_entry_zone_bounds()` 路径只要选中区命中且 `TRIGGER >= 10` 即可通过；没有要求触发必须由本次选中区域的后续回踩生成。
6. 实时刷新只刷新选中区域的位置状态，旧结构与旧触发仍可保留，导致“旧确认+当前下跌穿越”组合成新开仓。
7. v8位置选择可以读取全部15分钟均线区；当前强单边专用检查没有成为v8统一硬门槛。
8. 现有15分钟回踩触碰事实与区间名称不一致：部分触碰判断实际使用EMA9/BOLL中轨，输出却命名为EMA20/EMA60回踩，并可能把EMA20、EMA60、BOLL的最小值到最大值连成宽带。
9. 现有15分钟实时覆盖只更新多头候选，空头镜像不完整；而未闭合15分钟数据不应拥有自动开仓授权。
10. 价格推进效率会奖励一段干净上涨/下跌，但当前没有保证它只能确认趋势、不能替代回踩位置；趋势末端仍可能因为此前推进优秀而获得高总分。
11. 当前 `position.stop_price` 同时承担计划风险参考价和逐笔执行价，导致普通结构止损排在1小时/4小时收盘失效之前。
12. `_stop_exit_reason()` 未按真实 `stop_basis` 分类，多种结构止损命中后可能被统一写成“ATR波动硬止损”。

### 2.3 产品目标

本次改动只解决以下问题：

1. 让“位置优秀”继续代表“当前价格已进入建议入场位置”，同时保证建议区本身已经通过高周期准入。
2. 防止价格仅进入宽区间就获得自动开仓资格。
3. 建立行情状态与允许使用的入场周期之间的明确关系。
4. 让突破、回踩和重新确认成为有先后顺序的结构事件。
5. 保证触发与当前主入场区来自同一交易事实。
6. 将15分钟EMA20/EMA60严格限制在强单边战术入场中。
7. 将普通长线止损改为1小时/4小时实体收盘结构失效。
8. 保持评分、仓位、标的池及前端接口兼容，不通过新增大量参数解决问题。
9. 复用已有闭合K线突破/回踩判定，不再用新的指标或分数弥补事件链缺失。

- 不修改65/70/75三条开仓通道分数；
- 不增加新的技术指标或新的正向证据族；
- 不修改B/A/S首仓单位、杠杆或模拟本金；
- 不重新开启自动加仓或轮动；
- 不修改真实交易所下单；
- 不修改前端页面字段和展示逻辑；
- 不为了提高交易数量而降低位置或触发门槛。

## 3. 核心定义

### 3.1 “进入区间”

当前实时价格满足 `zone.low <= price <= zone.high`。该判定必须区分区域身份：

- 若只是原始候选参考区，命中不加位置分，也不显示优秀；
- 若已经是通过v5授权的建议入场区，命中后沿用现有逻辑，立即显示“优秀”并获得对应位置分。

区间命中本身不负责证明：

- 支撑/压力已经生效；
- 突破已经被市场接受；
- 回踩已经完成；
- 下跌已经止住或上涨已经受阻；
- 当前适合开仓。

### 3.2 “有效主入场区”

有效主入场区必须同时具备：

1. 明确方向；
2. 明确时间周期；
3. 明确结构角色，例如上升通道支撑、下降通道压力、突破后的角色互换位；
4. 普通行情以最新已闭合数据生成的1小时/4小时EMA20或EMA60独立区域为锚点；不要求价格进入该建议区后再等待下一次收盘；
5. 明确失效边界；
6. 来源事件没有被后续已收盘K线否定；
7. 区间不是多个遥远候选区的并集。

### 3.3 “位置优秀”

位置优秀的判定保持现有业务语义：

```text
建议入场区已通过v5来源授权
+ 当前价格位于该建议入场区
= 入场位置优秀
```

不得新增“进入建议区后还要再等收盘确认”这一门槛。收盘确认用于生成突破回踩区、授权15分钟强单边战术区，以及持仓后的结构止损；不用于延迟普通1H/4H建议区命中后的“优秀”判定。

### 3.4 “强单边”

强单边只由价格方向与结构建立，不再由RSI、资金费率、多空比、OI或成交量的“多项投票”授权。

强单边上涨的核心事实：

- 4小时方向看多或至少不反向，且1小时上涨结构已被收盘接受；
- 15分钟EMA20在EMA60上方，二者方向向上；
- 近期已收盘15分钟K线主要保持在EMA20/EMA60结构上方；
- 没有1小时/4小时已收盘结构失效。

强单边下跌完全镜像。

衍生品参与流和价格推进效率仍可提高机会分，但不能单独把普通趋势改成强单边状态。

## 4. 行情状态与允许入场周期

| 行情状态 | 多头允许主入场区 | 空头允许主入场区 | 15分钟EMA20/60权限 |
|---|---|---|---|
| 通道上涨 | 4H/1H EMA20或EMA60有效回踩；结构支撑负责共振与失效定义 | 默认不做逆势空，等待高周期方向改变 | 禁止作为独立主区 |
| 通道下跌 | 默认不做逆势多，等待高周期方向改变 | 4H/1H EMA20或EMA60有效反抽；结构压力负责共振与失效定义 | 禁止作为独立主区 |
| 强单边上涨 | 4H/1H EMA20或EMA60优先；允许15m EMA20/60战术回踩 | 禁止逆势空 | 仅多头允许 |
| 强单边下跌 | 禁止逆势多 | 4H/1H EMA20或EMA60优先；允许15m EMA20/60战术反抽 | 仅空头允许 |
| 震荡 | 4H/1H区间下沿与同周期EMA20/EMA60有效共振 | 4H/1H区间上沿与同周期EMA20/EMA60有效共振 | 禁止作为独立主区 |
| 趋势启动但未成为强单边 | 真实1H/4H角色互换位仅作观察；回踩同时触及HTF EMA20/60后才可执行 | 做空完全镜像 | 禁止仅凭15m均线开仓 |
| 高周期冲突/未知 | 不允许 | 不允许 | 不允许 |

这张表是入场区授权的唯一来源。评分、原因文案、setup名称、OI形态和智能资金标签都不能另行开放15分钟入场权限。

## 5. 主入场区选择规则

### 5.1 多头层级

按以下顺序选择唯一主入场区：

1. 4小时EMA20或EMA60的实际回踩区；若与4小时有效结构支撑重合，提升为结构优势；
2. 1小时EMA20或EMA60的实际回踩区；若与1小时有效结构支撑重合，提升为结构优势；
3. 已完成独立突破、回踩、收回事件的1H/4H角色互换位，且本次回踩同时触及对应1H/4H EMA20或EMA60；
4. 仅在强单边上涨时，选择15分钟EMA20/EMA60战术回踩区。

### 5.2 空头镜像

1. 4小时EMA20或EMA60的实际反抽区；若与4小时有效结构压力重合，提升为结构优势；
2. 1小时EMA20或EMA60的实际反抽区；若与1小时有效结构压力重合，提升为结构优势；
3. 已完成独立跌破、反抽、跌回事件的1H/4H角色互换位，且本次反抽同时触及对应1H/4H EMA20或EMA60；
4. 仅在强单边下跌时，选择15分钟EMA20/EMA60战术反抽区。

### 5.3 区域合并原则

- 使用重合区或最近的有效结构边界，不使用多个区域的外包并集；
- EMA20与EMA60分别建区；二者没有现有同周期容差内的真实重合时，禁止用最小值/最大值桥接成宽区；
- BOLL中轨、EMA9、VWAP、OI洼地和历史压力/支撑不得冒充EMA20/EMA60实际触及；
- 没有重合时不得为了制造入场区扩大上下边界；
- `breakout_retest`不得直接等于完整旧压力区；
- `breakdown_retest`不得直接等于完整旧支撑区；
- 过宽区域不能因为当前价格落在低侧/高侧就评为优势位置；
- 找不到单一明确主区时输出等待，不回退到最近任意指标区。

### 5.4 位置状态与分数

| 内部状态 | LOCATION | 是否允许自动开仓 | 含义 |
|---|---:|---|---|
| `UNAVAILABLE` | 0 | 否 | 没有合格主入场区 |
| `EXTENDED_OR_WRONG_SIDE` | 0 | 否 | 追价或处于错误一侧 |
| `APPROACHING` | 8 | 否 | 方向正确但尚未触及主区 |
| `IN_VALID_ZONE` | 15 | 是 | 当前价格进入已授权的1H/4H EMA20或EMA60建议区 |
| `STRUCTURAL_ADVANTAGE` | 20 | 是 | 当前价格进入HTF EMA20/60与同周期结构的优势重合区 |
| `M15_STRONG_TREND_RETEST` | 15 | 是 | 已由闭合15m确认并获授权的强单边战术区，当前价格命中 |
| `INVALIDATED` | 0 | 否 | 已收盘跌破/突破主区并使原交易假设失效 |

关键变化：

- “价格位于未经授权候选区”保持0分；“价格位于已授权建议区”仍立即获得15或20分并显示优秀；
- 真实角色互换位若没有与1H/4H EMA20或EMA60区域重合，只能作为结构观察，不得进入 `location_ready` 状态；
- 15分钟战术区最高15分，不得标记为高周期结构优势；
- `location_ready`由区域授权和当前价格命中共同产生，不新增命中后的收盘等待状态；
- 即使总分超过75、90或100，只要 `location_ready=false`，仍然不能开仓。

## 6. 突破回踩状态机

### 6.1 多头

```text
WAIT_BREAKOUT
    ↓ 1H/4H实体收盘站上有效压力边界
BREAKOUT_CONFIRMED
    ↓ 后续独立K线回到角色互换位，并真实触及1H/4H EMA20或EMA60
PULLBACK_TOUCHED
    ↓ 后续已收盘15m或1H K线重新站回正确一侧
RECLAIM_CONFIRMED
    ↓ 其他开仓门槛通过
EXECUTABLE
```

如果回踩后的已收盘K线跌破主区失效边界，则进入 `INVALIDATED`，必须重新等待新的结构事件。

### 6.2 空头镜像

```text
WAIT_BREAKDOWN
    ↓ 1H/4H实体收盘跌破有效支撑边界
BREAKDOWN_CONFIRMED
    ↓ 后续独立K线反抽角色互换位，并真实触及1H/4H EMA20或EMA60
RETEST_TOUCHED
    ↓ 后续已收盘15m或1H K线重新跌回正确一侧
REJECTION_CONFIRMED
    ↓ 其他开仓门槛通过
EXECUTABLE
```

### 6.3 事件一致性

1. 建立突破结构的K线不能同时充当回踩确认K线。
2. `trigger_event_id`必须晚于 `structure_event_id`。
3. 触发必须引用当前 `selected_level_key/source_event_id`。
4. 旧触发不得与后来选中的另一个主入场区组合。
5. 实时标记价不能凭空生成突破/回踩事件，但可以把一个已经授权的建议入场区从“等待价格”更新为“优秀/可执行”。
6. 新的已收盘K线负责生成角色互换事件与15分钟战术授权；普通1H/4H EMA建议区在授权后不再额外等待一根收盘K线。
7. 主区失效、方向改变或结构事件更新后，旧触发立即作废，不通过新增固定时长参数续命。
8. 新的同周期结构取代旧结构，或该结构链已完成一次开仓生命周期后，旧区进入 `EXPIRED`；价格重新进入旧数值范围不得使其复活。

## 7. 强单边15分钟战术入场

### 7.1 准入条件

只有行情状态为 `ONE_WAY_UP` 或 `ONE_WAY_DOWN` 时，15分钟EMA20/EMA60才进入可选主入场区。

强单边上涨多头必须满足：

- 4小时不反向；
- 1小时上涨结构有效；
- 已收盘15分钟EMA20 > EMA60且方向向上；
- 价格实际触及EMA20或EMA60其中一个独立区域；
- 后续已收盘15分钟K线重新站回并保持结构；
- 对应止损确认周期最低为1小时。

强单边下跌空头完全镜像。

### 7.2 明确禁止

- `TREND_LONG/TREND_SHORT` 普通趋势不能只凭15分钟均线开仓；
- 通道、震荡、方向未知不能只凭15分钟均线开仓；
- 趋势启动尚未确认强单边时不能只凭15分钟均线开仓；
- 未闭合15分钟K线只能用于实时提示，不得建立执行确认；
- EMA9或BOLL中轨的触碰不得冒充EMA20/EMA60触碰；
- EMA20与EMA60相距较远时必须拆为两个区域，二者之间的空白不得命中；
- 高分、短挤压/长挤压标签、OI洼地或成交放量不能绕过上述限制；
- 多头和空头必须完全镜像，不允许只更新多头15分钟候选区。

## 8. 评分与开仓策略兼容

### 8.1 保持不变

- 六个证据族及理论最高110分保持不变；
- 标准通道仍为 `score >= 75`；
- 趋势启动通道仍为 `score >= 70`；
- 模拟盘研究通道仍为 `score 65～69`；
- `DIRECTION/STRUCTURE/TRIGGER/PARTICIPATION/PRICE_PROGRESS`权重不因本PRD调整；
- 仓位等级、首仓单位和杠杆保持不变。

### 8.2 改变的只有LOCATION语义和执行门槛

- `PRICE_PROGRESS`继续衡量走势是否顺畅，但不能证明当前位置适合追入；
- `PARTICIPATION`继续确认资金持续性，但不能把错误位置变成优秀位置；
- `STRUCTURE`可以确认突破成立，但必须等待独立位置与触发；
- `TRIGGER`必须与选中主区一致，不能复用旧事件；
- 分数达标但主区未确认时，状态必须是等待位置或等待触发，而不是通过补分开仓。

## 9. 长线结构止损

### 9.1 普通止损

新v8自动模拟仓采用高周期收盘确认模式：

- 1小时主入场区：1H实体收盘确认结构失效后退出；
- 4小时主入场区：只接受4H实体收盘确认失效，普通1H波动不能全平；
- 15分钟强单边战术入场：入场可用15分钟确认，但普通止损确认周期最低为1小时；
- 单根15分钟或1小时影线触及后重新收回，不执行普通全仓止损；
- 多头使用支撑/通道下沿失效，空头使用压力/通道上沿失效，完全镜像。

### 9.2 ATR职责

ATR只用于：

- 在结构边界外提供波动缓冲；
- 估算计划风险和回测MAE；
- 辅助判断灾难保护距离。

ATR不得：

- 单独建立方向；
- 单独决定普通长线交易失败；
- 把普通结构参考价变成逐笔即时平仓价；
- 作为所有未分类止损的默认退出文案。

### 9.3 灾难保护

保留独立 `disaster_stop_price`，只防止极端跳价、行情数据中断和接近强平等异常情况。

- 灾难保护必须位于4小时灾难性结构失效之外；
- 不复用普通 `soft_stop_price`；
- 不以“距离开仓若干ATR”作为唯一依据；
- TP1之后已经进入盈利区的保护止损仍可以实时执行；
- 模拟盘必须单独统计灾难保护命中，不能混入普通结构止损。

### 9.4 时间退出

只要1小时/4小时入场结构仍有效，“若干周期未达到0.5R”不得单独触发亏损全平。

时间与推进不足只能：

- 标记观察；
- 禁止继续加仓；
- 在已有盈利时影响runner管理。

它不能替代结构失效。

## 10. 技术方案

### 10.1 `score_pipeline_v8.py`

重点调整：

- `location_for_selected_level_v8()`：保留已授权建议区命中后15/20分及“优秀”语义；授权过滤必须在调用前完成。
- `_select_location()`：按行情状态过滤允许的时间周期，再选择唯一主区；不得从所有候选区中简单选最近命中项。
- `_side_levels()`：返回候选区前增加授权过滤；15m EMA区只在强单边同向状态保留。
- `_trigger_evidence()`：要求触发与主区 `source_event_id`一致，并晚于触及事件。
- `_structure_stop()`：继续生成结构参考价，但不再默认代表逐笔普通止损执行价。

建议在现有 `LevelSelectionV8` 内部结构中补充带默认值的字段：

```text
timeframe
role
source_event_id
touch_event_id
confirmation_event_id
eligible
```

这些字段用于后端决策，不要求前端展示。

### 10.2 `paper.py`

重点调整：

- `_entry_level_context()`：停止把完整旧压力/支撑区直接映射为回踩确认区。
- 复用现有闭合K线1小时突破回踩判定；候选区只有消费到对应确认事件后才允许标记为 `breakout_retest/breakdown_retest`，不重复建立另一套相似阈值。
- `_entry_zone_bounds()`：只接受v5已授权的唯一主区；当前价格命中该区时继续返回有效边界。
- `_side_entry_timing()`：保留“当前价格命中合格建议区即 `GOOD`”的现有逻辑。
- `_refresh_score_model_v8_for_live_price()`：实时价格可把已授权主区从等待更新为优秀，但不得把未授权原始候选区升级为建议区。
- `_apply_live_m15_overlay()`：未闭合K线只作诊断；多空镜像；不直接改写可执行主区。
- `_entry_timeframe_for_signal()`：读取被授权主区的真实周期，不能仅根据字符串前缀推断业务权限。
- `_manage_open_position_v3()`：新计划版本把普通结构收盘失效放在初始逐笔止损之前。
- `_stop_exit_reason()`：按真实 `stop_basis/stop_execution_mode`分类，不再默认归类为ATR硬止损。

### 10.3 持仓计划版本

- 已有 `plan_version <= 3` 持仓继续按原规则管理，避免静默改变旧仓；
- 只有新开的v8自动模拟仓使用新计划版本；
- 手动/API开仓默认保持原逐笔硬止损行为，除非未来单独授权；
- 新计划分别保存结构参考价、收盘确认周期和灾难保护价，避免一个 `stop_price`承担三种职责。

### 10.4 `historical.py`

- 实时模拟盘与回测使用同一位置状态机和事件ID规则；
- 回测不得使用当前15分钟K线收盘前的数据完成收盘确认；
- 15分钟影线穿越普通结构价但收盘收回时，不再提前模拟全平；
- 同一历史输入必须得到与实时逐K回放一致的主区、状态、动作和退出原因。

## 12. 风险点

| 风险 | 影响 | 控制方式 |
|---|---|---|
| 建议区准入收紧导致交易减少 | 模拟样本减少 | 不增加命中后的收盘门槛；分别统计“无合格HTF主区”和“尚未进入主区” |
| 趋势启动无法回踩HTF均线 | 可能错过快速启动 | 未确认强单边时继续等待；确认强单边后才开放同向15m EMA20/60战术入口，不放宽普通通道规则 |

| 灾难保护与普通结构混淆 | 仍可能短期扫损 | 分离三个价格/模式并分别记录退出原因 |

| 多空镜像不完整 | 单边偏差 | 所有位置、触发、15m授权和止损测试均做严格镜像 |
| 为单个1000RATS案例过拟合 | 泛化下降 | 使用多币种、多行情状态和样本外区间验证 |

## 13. 改动计划

### P0：冻结与复现

- 保存1000RATS交易时点的1D/4H/1H/15m闭合K线、指标、候选区和事件ID；
- 固化现有v8输出与成交结果；
- 加入KOMA、FIL、AVAX、TAO及空头镜像黄金样本；
- 本阶段不改前端。

### P1：主区授权与位置语义

- 建立行情状态—允许周期矩阵；
- 普通行情过滤15m均线区；
- 修正 `breakout_retest/breakdown_retest`区域来源；
- 一个方向只保留一个主入场区；
- 合格建议区一旦被当前价格命中，继续立即评为优秀。

### P2：结构事件状态机

- 建立突破、触及、收回/拒绝三个独立事件；
- 绑定 `structure/source/touch/confirmation event id`；
- 实时价格刷新不得制造区域授权，但允许命中已授权建议区并更新为优秀；
- 主区失效或切换时清除旧触发。

### P3：强单边15分钟准入

- 用价格方向和结构统一定义强单边；
- 15m EMA20/60仅在强单边同向状态下参与；
- 完成多头与空头镜像；
- 未闭合15分钟K线只作提示。

### P4：长线结构止损

- 分离结构参考价、收盘确认模式和灾难保护价；
- 新自动模拟仓使用新的持仓计划版本；
- 普通结构止损等待1H/4H闭合确认；
- 修正退出原因分类；
- 旧仓、手动仓和旧成交保持兼容。

### P5：回测与模拟盘验证

- 实时与历史共用同一状态机；
- 对比当前v8与v5.0的交易数量、入场延迟、MFE、MAE、净期望R、Profit Factor和最大回撤；
- 单独统计“价格穿越区间但未收回”的拦截效果；
- 单独统计强单边15m战术仓表现；
- 不以胜率单项决定是否上线。

## 14. 验收标准

### 14.1 1000RATS黄金案例

在2026-08-03 12:55:57：

- 不得把 `0.0735699～0.0779901`仅因价格进入就评为优秀；
- 当前价格没有到达已授权的1H/4H EMA20/EMA60主区时，普通趋势不得开多；
- 即使总分达到开仓门槛，也不得自动开仓；
- 预期结果：`POSITION_PENDING`或等价等待状态，不产生该笔多单。

### 14.2 普通趋势与通道

- 普通上涨仅触及15m EMA20/60：不得开多；
- 普通下跌仅触及15m EMA20/60：不得开空；
- 当前价格进入已授权1H/4H EMA20/60建议区且其他门槛完整：立即评为优秀并允许进入对应开仓通道；
- 只完成1H/4H角色互换、但没有与1H/4H EMA20或EMA60区域重合：只观察，不得评为优秀或自动开仓；
- 震荡中部即使指标很多、总分较高：不得评为优秀位置。

### 14.3 强单边

- 强单边上涨回踩15m EMA20/60并闭合收回：允许成为多头战术主区；
- 强单边下跌反抽15m EMA20/60并闭合拒绝：允许成为空头战术主区；
- 4H反向、1H结构失效或未确认强单边：15m战术权限立即关闭；
- 多空镜像交换后，位置状态、分数绝对值和开仓结果严格对称。

### 14.4 突破回踩

- 同一根突破K线不能同时贡献结构和执行触发；
- 原压力/支撑区存在但没有完整事件链：不得生成 `breakout_retest/breakdown_retest`；
- 价格进入未经授权的旧压力/支撑区：不得获得位置分；
- 价格进入已经授权的唯一建议区：必须继续判定为“优秀”，不得新增收盘等待状态；
- 触发与主区事件ID不一致：不得开仓；
- 主区已失效：旧触发必须清除；
- 区域过宽或由多个区域并集形成：不得作为主区。
- EMA20与EMA60分离时，价格落在中间空白：不得判定命中。

### 14.5 止损

- 1H多仓盘中/影线跌破后收回：不平仓；空仓镜像；
- 新1H实体确认结构失效：平仓；
- 4H仓出现普通1H反向：不因该事实单独全平；
- 新4H实体确认失效：平仓；
- 15m战术长线仓普通止损确认周期最低为1H；
- 灾难保护仍可立即执行，但原因必须与普通结构止损区分；
- 新成交不得把 `v8_selected_structure`误写为“ATR波动硬止损”。

### 14.6 兼容与系统级

- 前端页面DOM结构、字段、列数、顺序、样式和交互无变化；
- API现有必需字段不删除、不改名；
- 旧持仓和历史成交行为不被静默改写；
- 实时与回测对相同闭合K线输入得到相同主区、位置状态、动作和退出原因；
- 不使用未来K线；
- 全量自动化测试通过；
- 仅因进入区间而输出“优秀”：0次；
- 普通通道行情使用15分钟位置授权开仓：0次；
- 未完成独立突破/跌破事件链却以角色互换区开仓：0次；
- 过期区、跨事件区、跨方向区开仓：各0次；
- 多空镜像一致率：100%；
- 至少完成200笔样本外生命周期交易对照；
- 不能只因胜率提高上线，净期望R、Profit Factor和最大回撤必须同时不恶化到不可接受水平。

## 15. 最终决策

本PRD不增加新的行情指标，也不通过调低开仓分数制造交易。它修正的是交易语义：

> 方向决定只做哪一边；行情状态决定允许使用哪个时间周期；1H/4H结构和EMA20/EMA60决定普通建议入场区；15分钟EMA20/EMA60只服务强单边战术；当前价格进入已经授权的建议入场区即判为优秀；普通亏损退出由入场所属1H/4H结构失效决定，ATR只做结构外缓冲。

在该原则下，1000RATS的12:55多单不应发生。先修正入场位置与时机，再评估止损放宽后的真实效果，避免把错误入场产生的损失全部归因于止损过紧。
