# PRD v6.0：策略信号否决精简与止盈止损阶段调整

## 文档说明

- 当前状态：方案确认阶段，尚未修改代码
- 适用系统：V8评分系统、实时模拟盘、历史回测
- 编写日期：2026-08-04
- 默认约束：不修改前端字段、表格列和页面布局
- 后续PRD默认统一使用本文件结构：需求说明、技术方案、兼容性问题、风险点、改动计划、下次优化建议

## 一、需求说明

### 1. 改动背景

当前策略信号的“否决”逻辑混合了四类不同情况：

1. 行情方向已经明确相反，确实不应该开仓；
2. 方向、结构、位置或触发暂时没有完成，只需要继续等待；
3. 行情数据缺失或过期，系统无法安全判断；
4. 开仓时才需要计算的止损、止盈和真实盈亏比。

目前存在以下主要问题：

- 等待条件被当成硬否决，容易让人误以为策略已经完全放弃该标的；
- 位置、触发和对应分数重复判断，同一个问题可能产生两到三个否决；
- 价格推进不足6分会阻止趋势启动交易，容易等价格已经涨起来以后才允许开仓；
- 策略信号页面没有止盈止损，但后台在信号阶段预先计算止损、目标和盈亏比，并以“缺少有效结构止损”“缺少真实结构目标”阻止信号；
- 当前价格已经进入合格建议入场区时，仍可能因为触发分不足而无法显示“优秀”，导致位置判断和触发判断互相影响。

这些问题让开仓条件越来越复杂，也增加了错过行情的概率。

### 2. 改动点

下面逐项列出当前实际否决代码及本次处理方式。

| 否决代码 | 当前含义 | 本次处理 |
|---|---|---|
| `CANDIDATE_ACTION_NOT_ESTABLISHED` | 多空分差不足，候选方向尚未建立 | 保留判断，但改为“等待方向”，不属于硬否决 |
| `PRICE_DATA_DISCONTINUOUS` | 15分钟、1小时或4小时价格K线不连续 | 保留阻断，归类为“数据不可用”；数据恢复后自动重算 |
| `PRICE_DATA_STALE` | 最新价格或必需K线数据已经过期 | 保留阻断，归类为“数据不可用”；数据刷新后自动恢复 |
| `H4_DIRECTION_OPPOSED` | 已闭合4小时方向与候选开仓方向明确相反 | 保留，作为V8唯一的策略硬否决 |
| `DIRECTION_CONFIRMATION_PENDING` | 高周期方向尚未确认，但没有明确反向 | 保留判断，改为“等待方向确认” |
| `CORE_STRUCTURE_UNAVAILABLE` | 核心结构分低于20，或核心价格结构尚未成立 | 保留判断，改为“等待核心结构” |
| `ENTRY_LOCATION_NOT_READY` | 没有合格建议入场区，或当前价格尚未进入建议区 | 保留判断，改为“等待入场位置” |
| `ENTRY_TRIGGER_UNAVAILABLE` | 独立收盘触发尚未确认 | 保留判断，改为“等待触发” |
| `STRUCTURE_STOP_UNAVAILABLE` | 策略信号预演没有生成有效结构止损 | 从策略信号中移除；止损改在真正开仓时生成 |
| `STRUCTURE_TARGET_UNAVAILABLE` | 策略信号预演没有生成真实结构目标 | 从策略信号中移除；止盈目标改在真正开仓时生成 |
| `NET_REWARD_R_UNAVAILABLE` | 策略信号阶段无法计算真实净盈亏比 | 从策略信号中移除；开仓执行阶段再计算 |
| `NET_REWARD_R_INVALID` | 策略信号预演的净盈亏比数据无效 | 从策略信号中移除；改为开仓执行校验 |
| `NET_REWARD_R_BELOW_MINIMUM` | 策略信号预演净盈亏比低于最低要求 | 从策略信号中移除；使用最终执行价格在开仓时校验 |
| `STANDARD_SCORE_BELOW_MINIMUM` | 正式通道评分低于75分 | 保留判断，改为“等待评分达到75分” |
| `RESEARCH_SCORE_BELOW_MINIMUM` | 研究通道评分低于65分 | 保留判断，改为“等待评分达到65分” |
| `STRUCTURE_SCORE_BELOW_MINIMUM` | 启动或研究通道结构分低于25 | 移除数值型否决；保留唯一的核心结构是否成立判断 |
| `LOCATION_SCORE_BELOW_MINIMUM` | 启动或研究通道位置分低于15 | 移除数值型否决；保留合格建议区授权和当前价格命中判断 |
| `TRIGGER_SCORE_BELOW_MINIMUM` | 启动或研究通道触发分低于10 | 移除数值型否决；保留一次独立触发是否成立判断 |
| `PRICE_PROGRESS_SCORE_BELOW_MINIMUM` | 启动或研究通道价格推进分低于6 | 移除硬否决；价格推进继续参与总分 |
| `ACTIVE_VETO:*` | 策略传入的通用传统硬否决 | 当前V8删除通用入口；以后新增硬否决必须单独评审和定义明确代码 |

上述处理可以归纳为：

| 处理类型 | 包含内容 |
|---|---|
| 保留为策略硬否决 | 仅 `H4_DIRECTION_OPPOSED` |
| 保留为数据阻断 | `PRICE_DATA_DISCONTINUOUS`、`PRICE_DATA_STALE` |
| 保留但改为等待 | 候选方向、高周期确认、核心结构、入场位置、独立触发、65/70/75分通道门槛 |
| 从策略信号移到开仓执行 | 结构止损、结构目标、真实净盈亏比 |
| 完全删除重复否决 | 结构25分、位置15分、触发10分、价格推进6分四项证据族最低分 |
| 删除通用旧入口 | `ACTIVE_VETO:*` |

明确保持不变的内容：

| 保持不变项目 | 现有规则 | 本次处理 |
|---|---|---|
| 4小时反向保护 | 4小时明确下行禁止做多，明确上行禁止做空 | 保留 |
| 核心结构要求 | 没有核心结构不能开仓 | 保留，状态改为等待结构 |
| 建议入场区授权 | 常规行情使用1小时/4小时有效结构区；强单边才允许15分钟EMA20/EMA60战术区 | 保留 |
| 当前价格要求 | 必须进入经过授权的建议入场区 | 保留 |
| 独立触发要求 | 没有触发不能真正开仓 | 保留，但与位置独立判断 |
| 总分门槛 | 研究65分、启动70分、标准75分 | 保留 |
| 价格推进评分 | 衡量价格路径和趋势质量 | 保留评分，只删除最低6分硬否决 |
| 模拟盘仓位 | B/A/S首仓一单位，S最高累计两单位 | 保留 |
| 旧持仓 | 按原有计划管理 | 保留，不重新计算 |
| 前端页面 | 现有字段、列和布局 | 保留，本次不改前端展示结构 |

### 3. 改动范围

本次改动范围包括：

- V8策略信号决策；
- 实时模拟盘自动开仓判断；
- 历史回测自动开仓判断；
- 新开仓的止损、止盈和真实盈亏比生成；
- 策略信号状态和否决原因来源；
- 相关自动化测试。

本次不改动：

- 前端字段、表格列和页面布局；
- 当前评分项目及各项目分值；
- 65分研究、70分启动、75分标准三个总分门槛；
- 合格建议入场区的高周期授权规则；
- 常规行情与强单边行情的15分钟入场区使用规则；
- 当前仓位分配和杠杆逻辑；
- 已有持仓的止损、止盈和出场规则；
- 手续费、滑点和资金费率计算方式。

## 二、技术方案

### 1. 当前交易逻辑与问题

| 当前逻辑 | 存在的问题 |
|---|---|
| 4小时明确反向时禁止对应方向开仓 | 正确，应保留 |
| 方向未确认也进入否决 | 应属于等待，不是方向错误 |
| 核心结构不足阻止开仓 | 应保留等待，但不叫硬否决 |
| 当前价格未到建议区阻止开仓 | 应保留等待 |
| 触发未完成阻止开仓 | 应保留等待 |
| 位置不足15分再次否决 | 与“未进入建议区”重复 |
| 触发不足10分再次否决 | 与“触发未形成”重复 |
| 价格推进不足6分直接否决 | 趋势刚启动时难以获得，容易错过早期机会 |
| 结构不足25分再次否决 | 与核心结构是否成立重复，形成20分和25分两套门槛 |
| 信号阶段缺少止损或目标被否决 | 信号阶段本来就没有最终执行价格，不应生成最终退出计划 |
| 信号阶段用预估盈亏比否决 | 最终成交滑点后可能完全不同，预估值不应决定策略信号 |
| 位置判断内部依赖触发分 | 导致缺少触发时同时出现位置和触发两种阻断 |

### 2. 优化后的交易判断顺序

#### 2.1 策略信号阶段

系统按照以下顺序判断：

1. 检查15分钟、1小时、4小时价格数据是否可用；
2. 判断候选多空方向；
3. 检查4小时是否已经明确反向；
4. 判断核心结构是否成立；
5. 选择经过授权的建议入场区；
6. 判断当前价格是否进入建议入场区；
7. 独立判断触发是否成立；
8. 判断总分是否达到对应通道；
9. 输出可执行信号或对应等待状态。

策略信号阶段不生成具体止损价、止盈价和真实盈亏比。

#### 2.2 三个开仓通道

三个通道继续保留：

| 通道 | 总分要求 | 其他必要条件 |
|---|---:|---|
| 研究通道 | 65分 | 仅模拟盘和回测；方向不反向、结构成立、位置优秀、触发成立 |
| 趋势启动通道 | 70分 | 临时启动方向成立、4小时不反向、结构成立、位置优秀、触发成立 |
| 标准通道 | 75分 | 正式高周期方向成立、结构成立、位置优秀、触发成立 |

价格推进继续参与总分，但不再要求必须达到6分。

例如某个趋势启动信号：

- 总分70；
- 核心结构成立；
- 当前价格进入合格建议区；
- 独立触发成立；
- 价格推进只有3分。

优化前会因为价格推进不足6分被否决；优化后可以进入趋势启动通道，因为它已经达到总分和全部核心交易条件。

#### 2.3 真正硬否决

V8本次只保留：

- 已闭合4小时方向明确反向。

以下情况不允许重新包装成其他硬否决：

- RSI极端；
- 单一多空比极高或极低；
- 拥挤证据不完整；
- 单独的OI、资金费率或大户多空比；
- 当前价格尚未进入建议区；
- 总分不足；
- 缺少止损、目标或盈亏比。

多头或空头拥挤仍按照现有规则进行风险扣分或提示，不直接一票否决。

#### 2.4 开仓执行阶段

当策略信号满足开仓条件后，再生成最终交易计划：

1. 确定包含滑点后的最终执行价格；
2. 根据本次选中的1小时或4小时结构生成结构失效位；
3. 生成最终结构止损；
4. 生成第一和第二止盈目标；
5. 计算手续费、滑点和不利资金费率后的真实净盈亏比；
6. 校验止损和止盈方向是否正确；
7. 校验真实净盈亏比是否达到现有最低执行要求；
8. 所有校验通过后，才扣除手续费、创建持仓和写入开仓成交。

成功开仓后，最终止损和止盈才写入持仓、开仓成交和持仓管理数据。

如果交易计划生成失败：

- 不创建持仓；
- 不扣手续费；
- 不修改余额；
- 不写入成交记录；
- 记录为开仓执行异常，不回写成策略硬否决。

普通自动策略仓不得重新使用ATR波动硬止损。ATR只能作为结构外缓冲或灾难保护的辅助。

### 3. 相比当前交易逻辑，本次优化好在哪里

#### 3.1 减少重复门槛

结构、位置和触发分别只判断一次，不再同时作为状态门槛和数值型否决。

#### 3.2 更容易捕捉趋势启动

价格推进效率继续帮助评分，但不再要求行情必须已经连续走出足够距离，减少等涨起来后才追多、等跌下去后才追空的问题。

#### 3.3 不降低核心入场质量

以下条件仍然必须满足：

- 4小时不能明确反向；
- 核心结构必须成立；
- 建议入场区必须经过授权；
- 当前价格必须进入建议入场区；
- 独立触发必须成立；
- 总分必须达标。

#### 3.4 解决入场位置与触发互相污染

价格进入合格建议区就显示“优秀”，触发不足只影响是否立即开仓，不再改变入场位置结论。

#### 3.5 止盈止损更加真实

使用最终执行价格计算退出计划，避免标记价格下盈亏比合格，但滑点成交后实际盈亏比已经不合格。

#### 3.6 策略解释更容易理解

最终只存在三类结果：

- 硬否决：4小时明确反向；
- 等待：方向、结构、位置、触发或分数尚未完成；
- 执行失败：实际开仓计划或账户条件不满足。

### 4. 本次解决的问题

本次方案解决：

- 同一事实重复否决；
- 价格推进不足导致趋势启动机会被错过；
- 触发不足导致优秀入场位置被错误取消；
- 信号阶段没有止盈止损却因缺少止盈止损被否决；
- 信号阶段预估盈亏比与最终成交盈亏比不一致；
- 开仓计划失败后可能污染策略信号原因；
- 等待状态、策略否决和执行失败混在一起的问题。

## 三、兼容性问题

### 1. 前端兼容

- 不新增、不删除、不重命名前端字段；
- 不修改策略信号、持仓和成交记录的表格结构；
- 新策略信号中的预估止损、目标和盈亏比字段保持为空或不返回具体数值；
- 成功开仓后的持仓和开仓成交继续正常返回最终止损止盈；
- 旧中文翻译保留，用于展示历史数据。

### 2. 旧信号兼容

- 入场策略版本从V5提升到V6；
- 已缓存的V5信号不能删除旧否决后直接开仓；
- 必须等待对应标的新闭合K线，重新生成V6信号；
- 评分模型继续为V8，不修改评分版本；
- 建议入场区授权版本继续为V5，因为本次不改变入场区资格；
- 持仓计划版本继续为V4，因为本次不改变已开仓后的出场管理。

### 3. 旧持仓兼容

- 已有持仓继续使用原止损、止盈和出场逻辑；
- 不重新计算旧持仓的保护价格；
- 不修改旧持仓的剩余数量和计划版本；
- 本次规则只作用于新生成的V6信号和新开仓。

### 4. 历史回测兼容

- 历史回测和实时模拟盘必须使用同一套信号判断和开仓计划生成逻辑；
- 回测只能使用当时已经闭合的K线；
- 不得使用未来结构补充当时缺失的止损或目标；
- V5和V6回测结果分开保存，不能混合统计胜率和收益。

### 5. 旧策略兼容

- V8以前的评分模型保持原行为；
- `strict_trend_entry=false`保持不变；
- 不重新启用旧的EMA、BOLL、RSI、成交量、OI、多空比严格否决；
- 仓位、杠杆、手续费、滑点和资金费率规则保持不变。

## 四、风险点

### 1. 开仓数量可能增加

删除证据族最低分后，65分和70分通道可能产生更多模拟交易。

控制方式：

- 总分门槛不变；
- 方向、结构、位置和触发仍然必须完整；
- 研究通道与其他通道分开统计；
- 先使用模拟盘和历史回测观察。

### 2. 假突破交易可能增加

价格推进不再必须达到6分，部分刚启动但最终失败的行情可能进入研究或启动通道。

控制方式：

- 保留核心结构和独立触发；
- 保留价格推进评分；
- 统计新增交易的胜率、净收益、最大有利波动和最大不利波动；
- 不针对单个币种新增参数。

### 3. 信号没有止损预演可能产生无保护开仓风险

控制方式：

- 最终执行价格确定后必须原子生成退出计划；
- 没有合法结构止损时不得真正创建持仓；
- 计划失败不能产生任何资金和成交副作用。

### 4. 滑点导致实际盈亏比下降

控制方式：

- 必须先确定最终执行价格，再计算止损、目标和净盈亏比；
- 标记价格下合格、最终成交价格下不合格时拒绝执行。

### 5. 等待条件仍可能出现在“否决”列

本次默认不修改前端字段和展示逻辑，页面上的列名仍然是“否决”。

控制方式：

- 后端先保证等待、硬否决和执行失败的决策逻辑分离；
- 是否将前端“否决”改成“等待/限制”，放到下次独立优化，不与本次策略逻辑混改。

### 6. 新旧信号混用

控制方式：

- 入场策略版本升级；
- 旧缓存信号等待新闭合K线重新评分；
- 已有持仓不迁移。

## 五、改动计划

### 第一阶段：保存当前基线

- 保存当前V5历史回测和模拟盘结果；
- 统计现有各类否决出现次数；
- 保存趋势启动、成熟趋势、震荡假突破和4小时反向样本。

### 第二阶段：精简策略信号判断

- 只保留4小时明确反向作为策略硬否决；
- 将方向、结构、位置、触发和评分不足改为等待状态；
- 删除四个证据族最低分否决；
- 删除策略信号阶段的止损、目标和盈亏比否决。

### 第三阶段：拆分位置和触发

- 入场位置只读取建议区资格和当前价格；
- 当前价格命中合格建议区立即显示“优秀”；
- 触发状态独立判断；
- 缺少触发时只产生等待触发，不再同时产生位置不足。

### 第四阶段：调整开仓计划生成

- 先确定最终执行价格；
- 再生成结构止损和止盈目标；
- 使用最终价格计算真实净盈亏比；
- 所有校验通过后再修改余额、手续费、持仓和成交；
- 失败时保证零副作用。

### 第五阶段：版本与兼容处理

- 入场策略版本升级到V6；
- 旧信号等待新闭合K线重算；
- 旧持仓保持原计划；
- 实时模拟和历史回测共用同一逻辑。

### 第六阶段：测试

至少覆盖以下情况：

1. 4小时明确反向继续禁止对应方向开仓；
2. 方向未确认只进入等待；
3. 结构不足只进入结构等待；
4. 当前价格未进入合格建议区只进入位置等待；
5. 当前价格进入合格建议区、触发不足时，位置仍显示优秀；
6. 价格推进0～5分不再单独否决；
7. 65分研究通道满足核心条件时可以开模拟仓；
8. 70分启动通道满足核心条件时可以开模拟仓；
9. 75分标准通道保持正常；
10. 信号缺少止损、目标和盈亏比时不被策略否决；
11. 开仓时无法生成合法结构止损则不创建持仓；
12. 最终成交滑点导致净盈亏比低于标准时拒绝执行；
13. 任一执行失败不扣费、不改余额、不写持仓和成交；
14. 旧持仓的止盈止损保持不变；
15. 实时模拟和历史回测结果一致。

### 第七阶段：模拟盘观察

重点统计：

- 候选信号数量；
- 等待信号数量；
- 真正硬否决数量；
- 实际开仓数量；
- 开仓计划生成失败数量；
- 65～69分、70～74分、75分以上的独立胜率和净收益；
- 新增交易的手续费后收益；
- 最大有利波动和最大不利波动；
- 相比V5减少了多少错过行情；
- 相比V5增加了多少错误开仓。

## 六、下次优化建议

### 1. 前端状态名称优化

在本次后端逻辑稳定后，再单独评估是否将策略信号栏的“否决”调整为更准确的名称，例如：

- 等待/限制；
- 当前限制；
- 未开仓原因。

该调整涉及前端展示，需要单独确认后再修改。

### 2. 研究新增交易质量

重点研究删除“价格推进至少6分”后新增的交易：

- 是否更早抓到趋势启动；
- 是否增加假突破；
- 入场后的最大有利波动是否改善；
- 是否减少追涨追空。

建议至少积累50笔新增交易后再决定是否调整价格推进评分，不根据单个币种修改。

### 3. 研究核心结构20分是否合适

本次删除“结构必须达到25分”的第二套门槛，但仍保留核心结构成立。

下一轮应根据真实样本比较：

- 结构20～24分交易；
- 结构25分以上交易。

如果20～24分交易明显较差，可以将其定义为独立的启动结构状态，而不是重新增加一个通用数值硬否决。

### 4. 执行失败原因统计

统计以下问题的出现频率：

- 核心结构成立但无法生成结构止损；
- 有结构止损但没有真实目标；
- 标记价格合格但最终成交价盈亏比不合格；
- 开仓执行异常。

这些问题应优先修复结构到交易计划的映射，不应通过增加评分参数掩盖。

### 5. 硬否决扩展规则

以后如果需要增加新的策略硬否决，必须同时满足：

- 使用已闭合K线；
- 与候选方向形成明确矛盾；
- 不能由已有方向、结构、位置或触发条件重复表达；
- 经过多标的历史回测和模拟盘样本验证；
- 单独形成PRD，不直接在现有逻辑中追加参数。
