# PRD v7.5：核心行情路由、两阶段交易计划与全链路可审计开仓

- 状态：终审通过稿，尚未落地代码
- 日期：2026-08-07
- 文档关系：本版本完整替代 v7.4；不得同时按 v7.4 的严格双轨门槛实施
- 运行时版本强制要求：market_state_version=4、channel_geometry_version=2、er12_formula_version=2、entry_pipeline_version=7、score_model_version=8、execution_plan_formula_version=2、position_schema_version=2、decision_reason_schema_version=2
- 适用范围：实时模拟盘、历史回测、新生成的自动策略信号与新开仓
- 前端约束：本次默认不新增、删除或重命名前端字段，不改变页面表格和布局

## 零、终审结论

v7.4 的方向是对的：后端统一输出五类行情、使用闭合K线、禁止未来重绘、区分信号与执行计划、所有未开仓原因可查询。

但 v7.4 不能原样实施。它把“识别真实通道”叠加成了六层门槛：

1. 完整配对双轨；
2. 固定最大宽度；
3. 9/12容纳率；
4. 独立斜率阈值；
5. EMA强制确认；
6. 几何成立后再等待两根1小时K线。

这会把肉眼清楚、项目现有代码也能识别的单边上升支撑、单边下降压力、阶梯趋势、突破回踩和早期趋势启动误判为不可交易震荡，重新造成多日不开仓。

v7.5采用以下减法原则：

- 五类行情负责描述市场与选择交易剧本，不负责删除已有有效结构策略；
- 上涨看主下轨，下跌看主上轨；主轨决定方向和失效，对侧轨主要服务目标；
- 配对轨、宽度、容纳率、EMA和衍生品都是质量信息，不重复成为“有没有趋势”的门槛；
- 市场分类与当前能否入场分开，放宽分类不等于追价开仓；
- 只保留语义事实、总分和最终执行计划，不新增任何分项最低分；
- 新分类器先影子运行，证明不会误删现有策略后才接管开仓。

## 一、需求说明

### 1. 改动背景

当前项目经历多轮优化后，已经形成一些应继续保留的好策略：

- 4小时下降压力附近优先寻找做空，而不是因低周期回踩做多；
- 4小时上升支撑仍有效时优先寻找做多；
- 下降压力突破回踩和上升支撑跌破反抽后，才允许方向翻转；
- OI洼地只在4小时已经确认看多且价格结构/位置setup成立后作为增强证据；
- 1H/H4真实支撑、压力和突破回踩优先于15分钟均线；
- 只有强单边才允许15分钟EMA20/EMA60成为独立战术入场区；
- OI、资金费率、多空比、主动买卖流只作评分与风险解释，不能改写价格方向；
- 证据族去重，位置、触发和价格推进不再设置独立最低分；
- 普通退出依赖1小时/4小时闭合结构失效，不使用ATR短周期硬止损；
- 模拟盘用于采集策略样本，不因累计亏损、回撤或连续亏损静默停开。

本次终审发现，v7.4如果直接实施，会破坏其中四项：

1. 严格配对通道会使现有4小时单边压力/支撑setup在评分前被过滤；
2. 五态先生成允许方向会使现有15分钟早期研究候选无法进入评分；
3. 新五态与旧trend_state/regime可能分别驱动开仓和持仓，形成“双脑”；
4. 结构分25仍可能成为与位置分、触发分相同性质的隐藏分项门槛。

### 2. 改动目标

本次目标只有六项：

1. 准确判断通道上涨、通道下跌、强单边上涨、强单边下跌、震荡；
2. 保留现有已验证的方向结构和setup，不因缺少对侧轨而取消方向；
3. 让满足公开流程的候选自动开仓，不存在后台隐形等待；
4. 让每个进入decision_universe但未开仓的标的都能在现有“否决”栏看到归类后的真实根因；池外与影子候选在标的池审计中查询；
5. 在开仓前完成结构止损、目标空间和最低1.30R审核，但不在策略信号阶段假装已有精确计划；
6. 实时、回测、开仓、加仓、止盈止损和出场共用同一行情状态真源。

### 3. 改动点横向对比

| 项目 | v7.4或当前风险 | v7.5最终方案 |
|---|---|---|
| 通道方向来源 | 完整双轨成立后才有方向 | 2点建立主轨，随后1次闭合回踩/反抽验证即可建立有序趋势方向 |
| 对侧轨 | 至少2个对侧反应，否则不是通道 | 对侧轨不是方向门槛；1个真实对侧极值可生成临时目标轨，2个以上提高可信度 |
| 通道宽度 | 大于4ATR直接归震荡 | 取消最大宽度硬门槛；宽度只记录，能否交易由位置、结构止损、目标和计划R决定 |
| 容纳率 | 最近12根至少9根在双轨内 | 取消硬门槛；保留为质量和审计信息 |
| 主轨斜率 | 另设S_channel12绝对阈值 | 只要求锚点方向真实抬高/降低且超过接触噪声，不再重复设置斜率门槛 |
| 边界容差 | 0.15ATR同时用于接触和失效 | 0.15ATR只用于接触；结构实体失效继续使用现有0.4ATR缓冲 |
| 强单边 | 结构、EMA、ER、D及脱离条件全部串联 | 只由闭合价格结构、未被反向结构破坏及未被通道/箱体容纳确定；EMA、ER/D只评分和说明 |
| 状态确认 | 几何完成后普遍再等两根1H | 核心事实闭合确认后立即生效；不再设置通用两根防抖 |
| 历史预热 | 80根不足可能全局无状态 | 80根为推荐预热；实际分支所需事实完整即可分类 |
| 4H EMA后备 | 弱EMA交叉也可能成为硬方向 | 无可靠4H结构时保留现有自适应强度分位保护；结构方向不重复要求EMA |
| 15m早期启动 | 五态无方向时在评分前被过滤 | 保留显式的模拟盘早期研究通道，但不得改写页面五态或绕过4H反向 |
| 方向选择 | 五态后仍可能要求多空8分差 | 单方向已获授权时不再二次选边；双向箱体由所处边界setup决定 |
| 结构分 | 结构25可能继续成为独立门槛 | 删除所有分项最低分硬门槛；保留语义结构成立和总分要求 |
| 评分与入场区顺序 | 先评分，但位置分又依赖入场区 | 先生成授权候选区，再计算评分和确定setup，最后审核当前价 |
| 止损 | 0.15ATR或ATR波动可能重新变成短止损 | 结构价为风险参考，普通出场只由闭合1H/4H结构失效触发；另设远端灾难保护 |
| 无历史目标的强趋势 | 可能因没有TP1/TP2永远不开仓 | 使用开放空间计划；不虚构远端目标，也不因价格发现自动拒绝 |
| 模拟盘账户风险 | 亏损/回撤可能再次禁止开单 | 继续计算并展示，但默认只提示；只有真实资金、容量和订单约束阻断 |
| 新旧行情状态 | 开仓读新状态，持仓仍读旧状态 | 每个决策版本只有一个真源；旧消费者只通过统一适配器读取 |
| 上线方式 | 分类器建好后直接接管 | 必须先影子运行、对比覆盖率并具备运行时回退 |

### 4. 改动范围

本次包含：

- 后端五类行情分类和4小时方向背景；
- 原有方向结构与新五态的兼容路由；
- 1H/4H授权入场区、15分钟早期研究和强单边战术区；
- V8评分、候选方向、setup、评级、固定资本单位与自动开仓流程；
- 两阶段交易计划、结构止损、目标空间和1.30R审核；
- 未开仓原因统一账本；
- 实时模拟与历史回测一致性；
- 新旧状态版本隔离、影子运行和回退。

本次不包含：

- 不修改前端字段、列、表格和布局；
- 不新增ADX、MACD等另一套趋势指标；
- 不修改评分证据族权重；
- 不恢复位置15、触发10、价格推进6或结构25等分项最低门槛；
- 不修改研究65、启动70、标准75三个总分入口；
- 不修改B/A/S首仓一单位、S最高累计两单位；
- 不用本PRD重算或迁移已有持仓的历史计划；
- 不恢复ATR短周期硬止损。

## 二、核心不变量与完整开仓流程

### 1. 核心不变量

以下规则优先级高于任何局部实现：

1. 4小时明确反向是唯一策略硬否决；
2. CLEAN_NEUTRAL不是否决，日线也不是方向待确认门槛；CONFLICT_NEUTRAL必须显示真实4H结构冲突；
3. 五态和4小时背景只决定允许方向及可用剧本，不重复加分；
4. 对同一事实的不同指标继续按证据族去重；
5. 不存在位置、触发、价格推进、结构等分项最低分；
6. 当前价进入仍有效的授权建议区，即判定“入场位置=优秀”；
7. 已授权1H/4H入场区命中后，不得再追加通用15分钟触发；
8. 信号阶段允许尚无精确止损、止盈和R；
9. 创建持仓前必须形成可执行的结构计划或开放空间计划；
10. 全部公开条件通过后，系统必须自动尝试一次且仅一次开仓；
11. 进入decision_universe后未开仓时，必须至少存在一个当前有效、中文、可查询的根因；池外与影子候选必须有可查询的池筛选结论；
12. 实时与回测不得读取未闭合K线或未来枢轴。

### 2. 最终开仓流程

~~~text
历史时点可评估全集与AUTO_TOP80候选池筛选
→ 行情数据完整性与连续性检查
→ 4H背景判断
→ 1H五类行情判断
→ 必要时建立15m早期研究候选
→ 按行情与原有setup生成相互独立的授权候选入场区
→ 对每个允许方向的setup/区域候选计算完整评分
→ 按现有稳定AUTO_TOP50主池规则形成decision_universe，未进入者写池审计
→ 审核每个候选的总分、setup有效性和当前价格是否入区
→ 已入区候选的入场位置=优秀
→ 为每个已入区且总分通过的候选生成结构失效、目标空间、止损、止盈/开放空间与计划R
→ 从计划通过的候选中按公开顺序确定最终方向、setup和建议入场区
→ 无策略硬否决、setup失效或数据阻断
→ 确定性派生S/A/B
→ 分配固定资本单位
→ 审核持仓、余额、保证金、最小订单和订单约束
→ 原子化自动开仓
~~~

流程不得变成“先算一个方向总分，再事后猜建议区”，否则LOCATION分会依赖一个尚不存在的区域；也不得先选未触价高优先setup，再让它遮住已触价候选。

### 3. 开仓资格唯一公式

~~~text
AUTO_OPEN_ELIGIBLE =
  symbol_and_price_data_pass
  AND allowed_direction_exists
  AND semantic_structure_exists
  AND setup_valid
  AND total_score_pass
  AND authorized_entry_zone_exists
  AND current_price_inside_zone
  AND execution_plan_pass
  AND capital_and_order_pass
~~~

location_status=EXCELLENT是“授权区存在＋当前价入区＋setup有效”的只读展示投影，不是第四次独立审核。allowed_direction_exists已经包含4H相容性。H4_DIRECTION_OPPOSED只生成同一事实的一条可见原因，不得在其他模块再次审核。不得在公式外再读取trigger_ready、location_ready、结构分最低值、多空8分差、日线待确认、高周期待确认或未展示的布尔条件。

semantic_structure_exists表示“存在能够授权该方向的价格结构事实”，不是结构分门槛；setup_valid只表示所选setup的固有闭合事实已完成且生命周期未失效。若二者来自同一个结构事件，保存并复用同一event_id，不得把同一事实审核两遍。

AUTO_OPEN_ELIGIBLE的权威取值时点是原子提交前：必须用final_fill_price和当时仍有效的同一快照完成最后一次重算后，才生成eligible_at_submit。decision_price阶段的结果只叫preliminary_eligible，不能进入“符合条件但未尝试开仓”验收分母。

该公式只对decision_universe成员求值；AUTO_TOP80影子候选未进入Top50不是公式内的策略否决，而是可查询的标的池结论。

## 三、五类行情与4小时背景

### 1. 周期职责

| 周期 | 职责 | 禁止事项 |
|---|---|---|
| 4小时 | 提供看多、看空、中性背景 | 不直接输出五态；不使用盘中4H |
| 1小时 | 输出唯一五类行情 | 不读取评分、持仓、动作或衍生品拥挤 |
| 15分钟 | 执行细化及显式早期研究 | 不改写五态；不推翻4H明确反向 |

市场状态每根闭合1小时K线更新；执行扫描可每15分钟运行，但必须使用当时最新闭合的1H和4H快照。

现有页面/API的interval选择器为兼容保留，但在entry_pipeline_version=7中只控制展示、取样视图或人工查询，不能改变自动决策周期。无论选择15m、1h、4h或1d，自动决策始终固定读取“4H背景＋1H唯一五态＋15m执行/早研”；服务端必须把view_interval与decision_timeframes分开，configure_interval不得再驱动另一套4H或1D入场信号。

每根新闭合1小时K线使用固定分类顺序：

1. 先用冻结边界审核旧主轨、旧配对轨和旧箱体是否失效；
2. 若更高跨度可靠箱体仍容纳当前价格，输出震荡；
3. 若同层级上涨主轨与下跌主轨同时有效且结构区间冲突，输出不可交易震荡并保存双方ID，不得按代码顺序选边；
4. 若可靠配对通道仍容纳当前价格，输出对应通道；
5. 若强单边三类核心事实成立，输出对应强单边；
6. 若单边主轨仍有效，输出对应通道并标记PRIMARY_RAIL_TREND；
7. 其余数据完整场景输出震荡。

这套顺序只确定市场状态，不代表当前可入场；入场仍由授权区、总分、位置优秀和执行计划决定。

### 2. 数据要求

- 只使用闭合OHLCV、ATR14、确认结构和价格推进事实；
- 实际参与计算的完整窗口必须连续，不能复用“只检查最近12根”的函数去审核60根窗口；
- 通道/箱体只要所需锚点和ATR完整即可分类；
- 强单边只要求其闭合价格结构窗口完整；ER_TR12和D12样本不足只影响对应评分与诊断，不得使五态不可用；
- 80根1H/4H仅为推荐预热，不是全局硬门槛；
- 枢轴只有在右侧两根对应周期K线闭合后可成为普通确认高低点；
- 主轨第三次验证可以是对既有两点轨道的当前闭合回踩/插针收回，不需要再等待该K线成为右确认枢轴；
- 数据缺失、不连续、过期或计算异常不得兜底为震荡。

### 3. 4小时方向背景

4小时按以下固定优先级判断：

1. 可靠价格结构优先；
2. 无可靠价格结构时，才使用现有EMA后备方向；
3. 上下结构冲突时为内部CONFLICT_NEUTRAL，不能与无明确结构的CLEAN_NEUTRAL混用；
4. 只有确认看多与候选做空、或确认看空与候选做多时，产生H4_DIRECTION_OPPOSED。

必须保留的可靠4H结构包括：

- DESCENDING_RESISTANCE；
- ASCENDING_SUPPORT；
- DESCENDING_BREAKOUT_RETEST；
- ASCENDING_BREAKDOWN_RETEST；
- 闭合突破/跌破和连续HH/HL或LH/LL结构。

这些结构继续决定方向、建议区和失效，不得降级成只用于页面说明。

4H单边主轨沿用与1H相同的“2点建线＋1次后续闭合验证”、稳定结构ID、冻结旧边界和确定性候选排序；区别只在于使用闭合4小时K线。多个4H结构冲突时输出中性并记录双方结构ID，不得按代码分支先后任意选边。

“2点建线＋1次验证”用于新五态和新通用主轨；不得反向成为现有H4专属setup进入评分的前置条件。现有H4下降压力、上升支撑和角色互换setup继续按其已验证规则建立，只要结构未失效就必须进入权威方向路由。

无可靠结构时的EMA后备方向必须保留项目现有自适应强度保护：

- 使用当前实现的EMA间距/ATR历史分位；
- 新进入方向使用现有55%分位要求；
- 已有后备方向保持使用现有35%退出分位；
- 连续两根闭合4小时确认；
- 未达到强度时保持CLEAN_NEUTRAL，不能据此否决另一方向。

可靠价格结构本身不再重复要求EMA分位。结构和EMA后备是先后关系，不是全部必须满足。

4H结构不得永久占用方向。结构ID在以下任一事件发生后失效或让位：

- 闭合4H实体越过冻结主边界及结构失效缓冲；
- 后续确认的镜像结构成立且其锚点时间晚于旧结构最后验证；
- 原摆动序列已被闭合突破/跌破和回踩确认替换。
- 较新的冻结4H箱体或中性摆动序列已经完整形成，且其全部必要锚点均晚于旧单边主轨最后验证；此时旧方向降为CONFLICT_NEUTRAL或CLEAN_NEUTRAL，不能继续永久否决。

不得用任意分钟数作为过期参数；也不得因旧趋势线“理论上尚未触碰”而永久硬否决新结构。

#### 3.1 唯一权威候选方向路由

候选方向只在本节点生成一次，H4_DIRECTION_OPPOSED也只在本节点登记一次。

本表中的“震荡且1H尚未建立趋势方向”严格等价于market_state=RANGE且range_tradeable=false；它不是第六种五态，也不是数据未知。range_tradeable=true继续只走箱体正确边界setup，数据不完整则先由数据阻断处理。

| 4H背景 | 1H五态/边界 | 当前已成立的setup | 最终候选方向 |
|---|---|---|---|
| 看多 | 通道上涨或强单边上涨 | 任一合法顺势setup | 多 |

| 看多 | 震荡且1H尚未建立趋势方向 | 合法15m早期研究多setup | 临时研究多方向 |

| 看空 | 震荡且1H尚未建立趋势方向 | 合法15m早期研究空setup | 临时研究空方向 |
| 看空 | 通道上涨、强单边上涨或不可交易震荡 | 有效H4做空压力/跌破反抽setup | 空；只能等待该H4 setup自身区域 |

H4专属反转setup必须先由闭合破位、回踩/反抽和支撑压力角色互换确认；确认后先更新4H背景，再进入本表。不得一边保留旧4H反向硬否决，一边又让新反转setup绕过它。

### 4. 主轨、接触和失效

上涨趋势以下方支撑主轨为核心，下跌趋势以上方压力主轨为核心。

主轨成立的最小事实：

~~~text
两个独立摆动锚点建立候选主轨
AND 后续一次新的闭合回踩/反抽或插针实体收回验证
AND 锚点方向真实抬高或降低
AND 主轨尚未被闭合实体有效破坏
~~~

锚点方向变化使用唯一公式：上涨要求anchor_price_2 - anchor_price_1不低于0.15 × ATR14_at_anchor_2_event，下跌要求其镜像值不低于同一阈值。ATR取第二锚点反应K线闭合时的同周期值，并随anchor_event和channel_geometry_version冻结；不得改用确认时、当前时或两个ATR中的临时最大值。

统一使用两个不同缓冲：

- touch_buffer = 0.15ATR：仅判断接触、影线刺穿和是否完整收回；
- structure_invalidation_buffer = 现有0.4ATR：判断1H/4H主轨或关键结构是否真正失效。

ATR取值时点固定：

- 锚点是否接触使用该反应K线闭合时同周期ATR14，并随anchor_event保存；
- channel_id/range_id确认时，将同周期0.4ATR绝对失效缓冲冻结在结构快照中；
- 后续ATR扩大或缩小不得改写旧ID的失效线、宽度或历史状态；
- 新setup生成时按当时冻结结构与当时ATR创建独立区域版本，区域在生命周期内不动态桥接扩大；
- 1H结构只使用1H ATR，4H结构只使用4H ATR。

上涨主轨：

- 收盘回到主轨正确一侧，才可增加验证或授权插针收回入场；
- 收盘在错误一侧但尚未超过0.4ATR时，结构暂存但不得新开仓；
- 收盘超过错误一侧0.4ATR，主轨失效。

下跌完全镜像。

0.15ATR不得替代现有0.4ATR去定义普通结构止损或持仓退出。

### 5. 配对轨的职责

配对轨不是通道方向成立的硬门槛。

- 一个真实对侧高点/低点可形成临时目标轨；
- 两个及以上独立对侧反应可形成高可信配对轨；
- 对侧轨用于压力/支撑、目标、是否追价和强单边升级；
- 缺少可靠对侧轨时，使用现有1H/4H真实压力或支撑作为目标候选；
- 不得用固定大ATR距离复制一条虚假平行线；
- 不设置最大4ATR宽度；
- 不设置9/12容纳率硬门槛；
- 不设置S_channel12独立最低值；
- 宽度、容纳率和拟合残差只进入审计和候选排序。

内部记录：

- channel_shape=PAIRED_GEOMETRIC_CHANNEL：主轨与可靠对侧轨均存在；
- channel_shape=PRIMARY_RAIL_TREND：主轨有效，对侧不规则或不足。

两者前端均使用五态中的“通道上涨/通道下跌”，但只有前者可直接使用对侧轨作为目标。

### 6. 通道上涨

必须满足：

1. 上升主下轨按2点建线＋1次后续闭合验证成立；
2. 最新闭合1H没有在主轨错误一侧超过0.4ATR；
3. 当前没有被仍有效的更高跨度冻结箱体容纳；
4. 当前未完成强单边上涨升级。

交易含义：

- 只在主下轨、同源1H/4H支撑或合法突破回踩区附近寻找多单；
- 对侧轨或其他压力主要作为目标；
- 价格远离主轨时仍可保持“通道上涨”，但不得追多；
- EMA、ER、D12和衍生品只作评分或说明。

### 7. 通道下跌

完全镜像：

- 下降主上轨由2点建线＋1次后续闭合验证；
- 只在主上轨、同源1H/4H压力或合法跌破反抽区寻找空单；
- 价格远离主轨时仍可保持“通道下跌”，但不得追空。

### 8. 强单边上涨与强单边下跌

强单边只保留三类核心事实：

1. 价格结构向该方向成立：闭合1H结构突破后没有收回原结构；或多头最近至少有两个确认摆动高点和两个确认摆动低点，并分别形成HH与HL，空头按两个确认高点和两个确认低点分别形成LH与LL；
2. 最近同向结构失效锚点仍有效，且尚未形成确认的镜像反向主轨；
3. 当前没有被有效配对通道或冻结箱体继续容纳。

ER_TR12和D12继续作为“价格推进质量组”保存连续值、进入现有评分和影子分层，但不决定五态、allowed_directions或15分钟战术权限，也不产生任何最低分或硬否决。首期可以观察以下分层：

| 观察项 | 多头高推进分层 | 空头高推进分层 |
|---|---:|---:|
| ER_TR12 | 不低于0.45 | 不低于0.45 |
| D12 | 不低于+1.50ATR | 不高于-1.50ATR |

上述0.45和1.50ATR只是统计分层线，不是交易阈值。这样不会把已删除的PRICE_PROGRESS最低分换名搬到五态上游。

EMA20/EMA60排列：

- 继续进入方向/结构评分和原因说明；
- 可作为价格运行质量与setup证据；
- 不与结构、ER和D12串联成五态硬条件；
- 不能单独建立强单边。

只有强单边允许15分钟EMA20/EMA60独立战术回踩/反抽区。为避免改坏现有M15_SQUEEZE_TACTICAL_LONG，本版保留其固有价格事实并增加完全镜像的M15_SQUEEZE_TACTICAL_SHORT；二者优先级均为95、生命周期完全镜像：

- 1H同向结构仍有效且4H不反向；
- 多头要求闭合15分钟EMA9 > EMA20 > EMA60、当前收盘不低于EMA20，且最近5根闭合K线至少4根收在EMA60上方；空头完全镜像；不新增EMA斜率门槛；
- EMA20区和EMA60区分别生成，不得把二者之间空白桥接为一个宽区；
- 闭合15分钟K线触及对应独立区后完成多头收回或空头拒绝；
- 止损/失效依据仍来自至少1H结构，不能使用15分钟EMA或ATR短止损。

这些是15分钟战术setup本身的成立定义，不是所有1H/4H建议区命中后的通用触发。即使是强单边，价格没有回到授权区也不得追价。

### 9. 震荡

不满足四类趋势状态且数据完整时，统一显示“震荡”。

内部只保留两个简单事实：

- range_tradeable=true：存在可靠冻结箱体；
- range_tradeable=false：过渡、收敛、发散或方向杂乱，没有可靠边界。

不再维护TRANSITION_CHOP和DIRECTIONAL_CHOP两套复杂确认状态机；具体原因写入range_reason。

可靠箱体核心条件：

- 至少2次独立支撑反应和2次独立压力反应；
- 上下边界由各自反应簇稳健中位生成；
- 两侧近似水平，反应簇偏差使用现有0.4ATR结构缓冲；
- 最新闭合价格仍在冻结边界内；
- 旧箱体未发生闭合实体结构失效。

箱体边界同样使用三区规则：完整收回箱内才可增加边界验证或授权假突破/假跌破入场；在边界外但未超过0.4ATR时只保留结构、不得新开仓；闭合实体越过冻结边界0.4ATR后旧range_id立即失效。0.15ATR只负责识别接触，不负责判定箱体失效。

箱体不设置最大4ATR宽度和9/12容纳率硬门槛。宽箱体能否交易由边界位置、结构计划和1.30R决定。

冻结箱体实体失效后：

- 旧range_id立即失效；
- 收回不能复活旧ID；
- 可把旧边界作为假突破收回setup的历史结构；
- 新箱体必须使用之后确认的锚点建立新ID。

只有range_tradeable=true且当前价在箱体边缘时允许交易；箱体中部不能显示位置优秀。

### 10. 结构优先级与嵌套结构

为避免在大箱体上沿因局部微型上涨通道做多：

1. 仍容纳价格的、更高跨度冻结箱体优先于其内部短跨度微型通道；
2. 有效4H主压力/主支撑优先于相反的短周期局部轨；
3. 同层级多个主轨候选按以下顺序选择：
   - 主轨有效验证次数更多；
   - 覆盖的独立摆动跨度更完整；
   - 最近一次验证更新；
   - 拟合残差更小；
   - 稳定结构ID作为最终平局键。

不得以“通道更窄”优先。

### 11. 状态生效、修订与禁止重绘

- 第三次主轨闭合验证完成时，通道状态立即生效；
- 箱体最后一个必要边界反应闭合时，可靠箱体立即生效；
- 强单边闭合价格结构事实成立时立即生效；
- 不再普遍追加两根1H确认；
- 只有旧结构未失效且新结构尚未完成时，页面可保持旧五态，但旧状态专属入场权限必须按当前可执行事实撤销；
- 每个历史决策快照不可修改；
- 新锚点可从确认时点向未来形成channel_revision或新channel_id；
- 破位K线不能重画旧ID，但未来经过右侧K线确认后可以成为新结构锚点；
- channel_id/range_id由版本、方向、锚点事件ID和确认时间生成稳定哈希；
- 同一输入无论集合顺序如何，实时与回测必须选择同一结构。

### 12. 15分钟早期研究通道

为保留KOMA类早期启动机会，15分钟不得改写五态，但可显式建立模拟盘早期研究候选。

早期研究分成前置候选与后置执行两层，禁止形成依赖环。

前置候选只要求：

1. 4H与候选同向或为CLEAN_NEUTRAL；4H反向和CONFLICT_NEUTRAL均不允许；
2. 1H尚未形成镜像反向结构；
3. 若1H仍被可靠箱体容纳，候选方向必须来自正确边界，不能在箱体上沿启动做多或下沿启动做空；
4. 闭合15分钟价格结构向候选方向成立，至少存在独立的突破回踩、跌破反抽或同向摆动收回事实；
5. 该结构能够生成镜像的M15_EARLY_STRUCTURE_LONG或M15_EARLY_STRUCTURE_SHORT、候选生命周期失效点和独立建议区；15分钟失效点只负责撤销早期候选，不得作为持仓的结构止损，也不得复用M15_SQUEEZE_TACTICAL的EMA区权限。

满足上述事实后先产生provisional_direction并进入正常流水。当前价入区、总分不低于65和执行计划通过均在后置通用流程审核，不得反过来参与早期候选生成。15分钟微结构证据继续进入总分，但不设置独立微结构最低分。进入执行阶段时仍必须找到方向一致、尚未失效的1H或4H结构锚点；找不到时保留信号并显示交易计划原因，不得把15分钟锚点提升为长线止损。

该路径：

- 只在模拟盘和对应历史回测中执行；
- 在原因中明确显示“1H五态尚未升级，当前为15分钟早期研究候选”；
- 不得绕过4H反向、总分、位置优秀、结构计划和1.30R；
- 不得把单根放量、OI或多空比当成方向；
- 不得静默存在。

## 四、评分、方向与入场区

### 1. 评分保持但不重复设门槛

继续使用当前V8完整评分和证据族去重：

- 均线/位置族：EMA20、EMA55、EMA60、BOLL中轨等同类事实只取最强项；
- 衍生品族：OI、资金费率、多空比、主动买卖流按现有上限处理，不重复叠加；
- 方向族：日线、4H、1H按现有有限共振逻辑计分；
- 触发族：1H/15m同源触发不得重复加分；
- 入场位置及真实空间、价格推进等继续进入总分。

五态名称不再额外加分。

删除以下独立硬门槛及其任何别名：

- LOCATION_SCORE_BELOW_MINIMUM；
- TRIGGER_SCORE_BELOW_MINIMUM；
- PRICE_PROGRESS_SCORE_BELOW_MINIMUM；
- STRUCTURE_SCORE_BELOW_MINIMUM；
- CORE_STRUCTURE数值最低分；
- trigger_ready；
- location_ready中的数值分要求。

语义结构成立、总分达标和当前价进入授权区仍必须满足。

### 2. 总分入口

| 背景 | 通道 |
|---|---|
| 4H与候选同向 | 标准不低于75；模拟盘研究65～74可按现有研究模式执行 |
| 4H为CLEAN_NEUTRAL且1H五态已有方向 | 启动不低于70；研究65～69可执行 |
| 15m早期研究候选 | 研究不低于65 |
| 4H明确反向 | 禁止对应方向 |

模拟盘的研究、启动和标准都是可执行样本通道，不是只展示不下单。任何通道未启用时必须显示具体配置原因，不能静默观察。

### 3. 方向选择

- 五态、4H背景和显式早期研究先生成allowed_directions；
- 多空两侧分数仍完整计算和展示；
- allowed_directions只有一个方向时，直接审核该方向，不再要求领先反向8分；
- 4H反向只审核一次，同时生成一条可见根因；
- CLEAN_NEUTRAL且1H无趋势方向时，如果同一快照的多空15m早期研究setup同时成立，则两侧都不进入执行并显示微结构冲突；不得按评分高低或集合遍历顺序暗中选边；
- 可交易箱体中，当前位于下沿只允许多头边界setup，位于上沿只允许空头边界setup；
- 若边界重叠或无法唯一确定setup，则显示“可靠入场边界未建立”，不得用多空分差暗中选边。

### 4. 原有setup必须保留

新五态只判断兼容性，不得把所有建议区统一替换为通道主轨。必须继续支持：

- 4H下降压力做空；
- 4H上升支撑做多；
- 下降压力突破回踩后的做多；
- 上升支撑跌破反抽后的做空；
- H1/H4真实支撑与压力；
- H1/H4突破回踩；
- 方向相容的1H/4H EMA20、EMA60和BOLL中轨独立主区；
- 现有H1_PULLBACK的VWAP回踩/反抽与MA20回踩/反抽独立区；
- H4看多价格setup叠加OI洼地证据；
- bearish价格setup叠加高位派发证据；
- 假突破/假跌破收回；
- 强单边15分钟EMA20/EMA60战术区。

成交量、主动买卖流、插针、回踩和假突破继续作为评分、setup质量、建议区依据或风险说明，但不进入五态分类。

其中：

- OI洼地只能在4H已看多且价格结构/位置setup已经成立后，作为参与流和位置增强证据；不得独立创建方向、入场区、止损或优先级；
- 高位派发必须先映射到真实的bearish价格结构或压力拒绝；成交量/OI标签本身不得独立创建做空方向和入场区；
- 现有OI_VALLEY_REVERSAL_LONG与DISTRIBUTION_STAGE1/2/3的setup_id和生命周期可保留，但前者必须先有H4看多及价格收回，后者必须先有bearish价格结构；名称中的OI/派发标签不能单独建立方向；
- 删除的是所有setup之外的通用触发，不是setup固有事实。突破回踩、跌破反抽、假突破收回、假跌破收回、H1_PULLBACK的闭合hold/reject及15分钟战术区仍必须完成各自的闭合确认；
- KC继续按现有逻辑作H1_PULLBACK评分/质量证据，不在本版新增KC独立入场区。

### 5. 候选入场区选择

每个setup和每个建议区独立生成、独立判断是否命中，禁止：

- 把1H/4H EMA20与EMA60之间的空白桥接成一个宽区；
- 把EMA/BOLL区与主轨、支撑压力区合并成一个“只要碰到任意位置都算命中”的大区；
- 用一个setup的触发去授权另一个setup；
- 让尚未触价的旧高优先区遮住已经触价且计划合格的新区域。

同一方向存在多个合法候选区时，先筛选“当前已命中且各自执行计划通过”的集合。对现有setup_id，先沿用当前_setup_priority，不得让新五态类别顺序覆盖原优先级；唯一有文档依据的镜像修正是H4上升支撑多头获得与H4下降压力空头相同的effective priority：

| 现有setup_id | 保留优先级 | 兼容要求 |
|---|---:|---|
| H4_DESCENDING_RESISTANCE_SHORT | 100 | 结构未失效且路由允许做空 |
| H4_PULLBACK_LONG且source_structure=ASCENDING_SUPPORT | effective 100 | 不新增存储ID；只对已确认的4H上升支撑镜像生效 |
| M15_SQUEEZE_TACTICAL_LONG / SHORT | 95 | 保留现有多头固有事实并新增完全镜像空头；只在强单边战术权限成立，不借早期研究绕过 |
| OI_VALLEY_REVERSAL_LONG | 95 | H4先看多，且价格收回setup本身成立 |
| DISTRIBUTION_STAGE1_SHORT / STAGE2_SHORT | 95 | bearish价格结构或压力拒绝先成立 |
| DISTRIBUTION_STAGE3_SHORT | 90 | 同上 |
| 其他H4_PULLBACK_LONG / SHORT | 85 | 保留现有H4独立区与闭合事实 |
| H1_PULLBACK_LONG / SHORT | 75 | 保留EMA/BOLL、VWAP和MA20独立区及1H闭合hold/reject |
| H1_STRUCTURE_LONG / SHORT | 65 | 保留现有结构事件与独立区 |

OI/派发的优先级属于已成立的“价格setup整体”，不是给衍生品证据单独加优先级。effective priority只在内存决策排序中派生，不重写旧setup_id。新增主轨、箱体边界等setup只有在没有更高优先级的已命中且计划通过的现有setup时参与排序；其内部顺序为4H结构、五态主边界/箱体边界、1H/H4结构区、独立EMA/BOLL区、强单边1H回踩、强单边15分钟战术区。

优先级相同时按：

- 与当前价尚未失效；
- 结构时间级别更高；
- 最近确认更新；
- setup_id稳定排序。

不得选择更远的目标或更近的止损来反向优化R。

如果当前没有区域命中，策略信号可继续展示多个独立建议区，但必须显示当前价格尚未进入任何授权区。若多个区域命中但没有计划通过，分别保留计划失败根因后归类显示。

新主轨和箱体边界的“附近”不是新增门槛，而是把既有current_price_inside_zone定义为确定性区间，统一纳入entry_pipeline_version=7及配置哈希：

~~~text
上涨主轨多区(t) = [frozen_lower_rail(t), frozen_lower_rail(t) + frozen_touch_buffer_abs]
下跌主轨空区(t) = [frozen_upper_rail(t) - frozen_touch_buffer_abs, frozen_upper_rail(t)]
箱体下沿多区    = [frozen_range_low, frozen_range_low + frozen_touch_buffer_abs]
箱体上沿空区    = [frozen_range_high - frozen_touch_buffer_abs, frozen_range_high]

frozen_touch_buffer_abs = 0.15 * ATR14_1H_at_setup_creation
~~~

主轨函数由冻结锚点向当前决策时点投影，不能用新高低点回改；缓冲绝对值在setup创建时冻结。当前成交价必须位于结构正确一侧；错误一侧只保留结构观察，闭合收回后才能创建新的授权setup。现有H1/H4支撑压力、突破回踩及EMA/BOLL独立区域继续使用各自当前公式，不统一改成上述窄带、不桥接，并把最终上下界和公式版本写入快照。

### 6. 入场位置优秀

位置优秀只由三个事实决定：

1. 建议区被当前行情和setup授权；
2. 当前可成交价格进入建议区；
3. setup尚未失效。

满足即为EXCELLENT。位置分高低、额外15分钟形态或触发分不得推翻。

通道行情只允许在主轨或同源结构区优秀；仅仅“还在通道内”不等于优秀。

候选建议区必须按冻结主轨、箱体边界和结构失效侧裁剪。任何延伸到结构错误一侧的0.4ATR普通建议区都不得仅因数值命中而评为优秀；只有闭合K线完整收回正确一侧后才能重新授权。

## 五、两阶段交易计划

### 1. 第一阶段：策略信号

策略信号必须保存：

- 方向和五态；
- 4H背景；
- 总分、评分版本与证据摘要；
- setup_id；
- 建议入场区；
- 结构失效锚点或等待原因；
- 目标候选，或是否属于开放价格空间；
- 当前价格是否进入区间；
- 全部当前有效未开仓原因。

此阶段不要求精确止损、TP1、TP2或净计划R。缺少精确数值不得产生策略硬否决。

缺少结构失效锚点时，信号可以展示，但不能进入执行阶段；页面显示“方向、结构与市场环境：结构失效锚点尚未形成”。

### 2. 第二阶段：开仓执行计划

对每个“价格已进入独立建议区、总分已通过”的候选，按同一个最终模拟成交价完成：

1. 锁定setup及主结构失效锚点；
2. 生成结构失效参考价；
3. 识别最近有效对手结构；
4. 生成有界目标计划或开放空间计划；
5. 计算手续费、滑点和计划R；
6. 审核最低1.30R；
7. 在全部计划通过候选中按4.5节公开顺序确定最终setup；
8. 派生评级；
9. 分配固定单位；
10. 审核账户和订单；
11. 原子化创建持仓。

市场计划、评级、资金审核不能分别重复检查同一个账户条件。

#### 2.1 统一价格、费用和R公式

execution_plan_formula_version=2固定以下口径：

1. 先按交易所tick_size得到预计模拟成交价E；本节全部R按每单位计算，不依赖数量Q；
2. 由选中setup唯一确定结构失效参考价S，不允许为提高R改选更近锚点；
3. 用当前已配置的手续费率和模拟滑点模型计算每单位开仓成本、结构失效退出成本和目标退出成本；
4. 多头与空头完全镜像，所有距离均按有利/不利方向取正值；
5. 价格取整后必须重新审核方向关系、区域命中和R；数量取整留到评级与固定资本单位之后。

每单位预计风险：

~~~text
risk_unit =
  abs(E - expected_structure_exit_price)
  + entry_fee_unit
  + invalidation_exit_fee_unit
~~~

S已经包含冻结边界外0.4ATR结构缓冲。expected_structure_exit_price以S为基准，按不利方向取整并加入当前版本模拟退出滑点；退出滑点已包含在该价格与E的距离中，只允许计入一次，不得再追加独立滑点项。计划时无法知道未来确认K线会越界多少，因此不把未来越界幅度伪装成已知输入；真实退出仍按确认K线后的下一可执行价格成交，并单独记录expected与realized差异。它是保守估计，不是保证损失。

有界目标模式下，沿用当前版本化的TP分配权重w_i，且权重、手续费和滑点随决策快照保存：

~~~text
bounded_reward_unit =
  sum(
    w_i * (
      abs(T_i - E)
      - target_exit_fee_unit_i
      - expected_favorable_exit_slippage_unit_i
    )
  )
  - entry_fee_unit

net_plan_R = bounded_reward_unit / risk_unit
~~~

未分配给固定目标的趋势仓权重在准入计算中按0收益处理，不能用未知的runner收益抬高R。risk_unit不大于0、目标方向错误或取整后关系失效时，计划无效。

### 2.2 决策价格与竞态

每次决策冻结：

- decision_as_of；
- decision_effective_at；
- first_executable_at；
- 1H/4H/15m数据截止时间；
- decision_price；
- setup_id和区域版本；
- 所有运行时版本。

统一可成交时点：decision_effective_at必须晚于本次所用最后一根闭合K线并在decision持久化完成后生效；实时交易的first_executable_at是其后的第一笔可执行交易所报价，回测使用下一根15分钟K线open作为该报价的离散近似。不得用生成decision的同一根15分钟K线high/low回填成交。挂单式区域在first_executable_at之后才允许按统一缺口和触及规则成交。

提交前使用final_fill_price重算区域命中、费用、滑点和计划审核：

- 快照和setup未变化、最终价仍在区内时，可在同一decision_id内完成这一次原子尝试；
- 最终价离区或计划不再通过时，本decision拒绝并显示实际原因；
- 已出现新的闭合执行K线、setup或结构版本变化时，旧decision标记STALE_SNAPSHOT；重新评估必须产生新decision_id；
- 缺口成交价同样必须重新通过区域和1.30R/空间审核，不能沿用旧计划。

### 3. 结构止损语义

必须区分：

- structure_invalidation_price：结构失效参考价，用于计划风险和闭合K线退出；
- disaster_stop_price：远端灾难保护，只处理极端跳价、数据中断或系统异常。

普通长线仓位不因盘中价格瞬时触及structure_invalidation_price立刻止损。正常退出要求：

- 对应1H或4H闭合实体确认结构失效；
- 使用冻结边界和0.4ATR结构缓冲；
- 在下一可执行价格完成模拟退出并记录滑点。

计划R的风险分母使用结构失效参考价、预计退出滑点和费用，必须明确它是预计值而非保证值。不得恢复ATR波动硬止损。

灾难保护使用确定性且独立于普通止损的首期公式：

~~~text
disaster_distance =
  max(
    abs(E - structure_invalidation_price),
    ATR14_1H_at_plan
  )

long_disaster_candidate  = structure_invalidation_price - disaster_distance
short_disaster_candidate = structure_invalidation_price + disaster_distance
~~~

若存在有效的预估强平安全价，最终灾难价取“结构外候选”和“强平安全价”中更靠近入场、且仍位于结构外的一项；多空完全镜像。ATR只在这里帮助形成极端尾部保护，不得触发普通策略退出。灾难价在计划创建时冻结、按不利方向取整，不能用于美化net_plan_R。

同时记录：

- expected_structure_loss：按闭合结构退出估算；
- worst_case_disaster_loss：按灾难价、费用和滑点估算。

模拟盘继续采用固定资本单位，两项风险均展示和统计；本PRD不新增单笔或组合风险硬门槛，也不因历史亏损禁止开仓。灾难价无法生成、方向错误或已越过预估强平安全边界时，属于可见的系统/下单阻断。

### 4. 目标与开放空间

有真实对手结构时：

- TP1/TP2按最近有效压力/支撑顺序生成；
- 不得跳过最近压力去选择远端目标凑1.30R；
- 对侧轨只有可靠时才可作为真实目标。

强单边处于历史新高/新低或没有可靠对手结构时：

- 标记plan_target_mode=OPEN_SPACE；
- 不虚构固定远端压力/支撑；
- 使用与有界模式相同的risk_unit、费用、滑点和取整口径，求出“假设全量退出时净R恰好为1.30”的参考价P_1_30R；
- 检查从成交价到P_1_30R之间是否存在已知对手结构；
- 没有已知障碍时记为open_space_capacity_R不低于1.30并通过空间审核；它不是已经实现的收益，也不显示成确定目标；
- 闭合1小时价格首次达到P_1_30R后，仅把状态改为PROTECTION_ELIGIBLE，不立即设置盘中保本价或强制全平；
- 费用后保本参考价按最终成交价、实际开仓费率、当前版本预计退出费率/滑点及tick_size求解：多头取“预计净收益不小于0”的最小合法价格，空头取最大合法价格，并随持仓计划冻结；
- 此后只有形成新的同向闭合1H保护摆动，且该摆动的结构失效价已经越过费用后保本参考价时，才冻结新的protected_structure_invalidation_price；多头保护价只能上移、空头只能下移；
- 退出仍要求后续闭合1H实体使该保护结构失效，并在下一可执行价格成交。若尚未形成新的1H保护摆动，继续沿用原结构计划，不得把任意价格回撤包装成“保本保护”；
- 剩余仓位按1H/4H结构、趋势回撤保护和已有分批止盈逻辑管理；
- OPEN_SPACE的TP1/TP2可为空，但原因和计划模式必须可审计；BOUNDED_TARGETS继续沿用现有双TP要求。

OPEN_SPACE必须有明确的数据兼容分支，不能被现有双TP模型补成默认止盈：

- position_schema_version=2的新持仓必须保存plan_target_mode=BOUNDED_TARGETS或OPEN_SPACE；
- BOUNDED_TARGETS继续要求现有合法TP1/TP2并沿用原分批止盈；
- OPEN_SPACE允许take_profit_1/take_profit_2为空，P_1_30R只保存到独立open_space_reference_price，绝不能回填成TP1或TP2；
- 开仓默认目标补全、退出计划校验、PortfolioRiskGate输入模型TradePlan、RiskDecision兼容模型、持久化/恢复、TP命中、分批减仓、持仓管理、API序列化和页面空值格式化都必须先按plan_target_mode分支；OPEN_SPACE不得调用双TP命中逻辑；
- TradePlan和需要承载新计划的RiskDecision将TP字段改为可空并携带target_mode；OPEN_SPACE的计划合法性只校验入场、结构/灾难止损、杠杆和费用为有限合法值，账户风险预算仍只按entry、stop、数量及成本计算，不得因TP为空返回INVALID_TRADE_PLAN；旧RiskManager双TP路径继续归LEGACY_BOUNDED_DUAL_TP；
- 旧持仓或旧payload没有plan_target_mode但存在两个数值TP时，确定性解释为LEGACY_BOUNDED_DUAL_TP并保持原行为；
- 前端字段和布局不变；OPEN_SPACE的现有止盈字段返回空值，页面显示为空，不显示P_1_30R为承诺止盈。

### 5. 评级与固定资本单位

- 评分通道通过后，S/A/B必须由现有评级规则确定性派生；
- 评级不得再附加未公开质量门槛；
- 评级计算异常属于系统错误，不得变成“不评级所以不开仓”；
- B/A/S首仓均为1单位；
- S只允许后续加仓到最高2单位；
- 仓位风险指标继续计算和展示。

评级和固定资本单位确定后，才按单位保证金、杠杆、final_fill_price及step_size计算最终Q。账户/容量审核使用该实际Q；提交前复核最小名义金额、总手续费、余额与保证金，但不得再生成第二套计划R或重复审核同一账户条件。若实际E变化，按2.2节重算每单位R；Q本身不改变R。

### 6. 原子执行

执行前最后检查：

- 决策快照仍是当前版本；
- 价格仍在授权区；
- setup_id未变化；
- 没有同标的持仓；
- 容量、余额、保证金、最小订单和下单精度通过；
- decision_id尚未提交。

任一失败均不扣费、不改余额、不写持仓、不写成交，并登记可见原因。全部通过时每个decision_id只允许一次开仓尝试。

## 六、未开仓原因与策略硬否决

### 1. 策略硬否决

新版本只保留一个策略硬否决：

- H4_DIRECTION_OPPOSED：已闭合4小时方向与候选方向明确相反。

日线反向、4H为CLEAN_NEUTRAL、EMA未共振、多空比极端、衍生品缺失和分项分数不足都不是策略硬否决。CONFLICT_NEUTRAL属于可见的结构冲突等待，不伪装成H4_DIRECTION_OPPOSED。

### 2. 所有可见阻断分类

| 页面分类 | 可能阻止开仓的根因 |
|---|---|
| 标的资格与行情数据 | 不在历史时点标的池、合约不可交易、流动性不合格、必需价格K线缺失/不连续/过期、分类计算异常 |
| 方向、结构与市场环境 | 4H明确反向、没有允许方向、可靠价格结构尚未成立、冻结结构已失效、结构失效锚点尚未形成、当前为不可交易震荡、早期研究条件未成立 |
| 评分与入场 | 总分低于适用65/70/75门槛、没有授权建议区、当前价格未进入建议区、setup结构事件已失效或被新事件取代、最终成交价离开建议区 |
| 交易计划 | 结构失效价无法合法生成、最近目标或开放空间无法验证、计划关系无效、净计划R低于1.30R |
| 资金、仓位与交易限制 | 已有同标的持仓、容量已满、固定单位无法分配、可用余额/保证金不足、最小订单不满足、明确启用的账户硬限制 |
| 系统与下单 | 策略服务关闭、灾难保护配置/生成失败、调度异常、快照冲突、重复decision_id、订单或持久化失败 |

衍生品数据缺失：

- 只使相关证据贡献0分并显示风险提示；
- 不封顶研究通道；
- 不产生全局红色错误；
- 不阻断其他标的。

### 3. 明确删除的阻断

新版本不得生成或变相恢复：

- LOCATION_SCORE_BELOW_MINIMUM；
- TRIGGER_SCORE_BELOW_MINIMUM；
- PRICE_PROGRESS_SCORE_BELOW_MINIMUM；
- STRUCTURE_SCORE_BELOW_MINIMUM；
- ENTRY_TRIGGER_UNAVAILABLE；
- 因位置分产生的ENTRY_LOCATION_NOT_READY；
- STRUCTURE_STOP_UNAVAILABLE作为信号硬否决；
- STRUCTURE_TARGET_UNAVAILABLE作为信号硬否决；
- 信号阶段净R不足；
- 日线方向待确认；
- 4H中性待确认；
- 单方向候选的多空8分差不足；
- 多空比或拥挤观察单独阻断；
- 模拟盘累计亏损、回撤和连续亏损默认阻断。

### 4. 原因账本

集合定义：

- evaluation_universe：历史时点已经上市且可被池筛选器评估的USDT永续合约全集；
- scored_shadow_universe：按历史时点成交额进入现有AUTO_TOP80候选并完成信号/评分计算、但不必拥有自动开仓资格的集合；
- decision_universe：按现有AUTO_TOP50主池规则和稳定排序进入本轮自动开仓决策的集合；已有持仓继续管理，但不重复进入新开仓decision_universe；
- pool_rejected：evaluation_universe减去decision_universe，其中必须区分“未进Top80”和“已评分但未进Top50主池”。

池筛选器为evaluation_universe中的每个标的保存轻量pool_evaluation_id、历史排名、阈值及通过/拒绝事实，供审计查询；不要求把全部池外或Top80影子候选塞进策略信号表。只有进入decision_universe时才生成新开仓decision_id和只追加原因账本。页面“未开仓必有原因”、AUTO_OPEN_ELIGIBLE等式和开仓尝试统计的分母均为decision_universe；scored_shadow_universe减去decision_universe的标的只能用于研究和池审计，不能被计为漏开仓，也不能绕过Top50主池直接交易。

每个原因至少保存：

- 分类；
- 中文根因；
- 来源阶段；
- 实际值与要求值；
- ACTIVE、RESOLVED或NOT_RUN_UPSTREAM_BLOCKED状态；
- setup_id、行情版本和数据截止时间；
- 是否真实阻止本轮开仓。

原因账本只追加、不原地修改：ACTIVE变为RESOLVED或NOT_RUN_UPSTREAM_BLOCKED时，追加新的reason_event并引用previous_reason_event_id；历史事件保持不变，当前状态由每个根因最新事件投影得到。

页面仍使用现有“否决”栏：

- 每类最多一行；
- 同类分号合并；
- 同根因去重；
- 多个独立根因全部显示；
- 上游失败时不虚构下游失败；
- 不展示英文原因码；
- 不使用“其他条件未满足”等无法查询的文案。

eligible_at_submit=true但没有开仓尝试，视为P0缺陷。

## 七、相比现有交易逻辑的收益

### 1. 保留原有好策略

五态不再抢走4H下降压力做空、上升支撑做多、突破回踩、真实支撑压力和15分钟早期研究的交易资格。

### 2. 减少误判而不是堆参数

通道只看主轨是否被市场持续尊重；对侧轨负责目标。宽度、容纳率、EMA和衍生品不再重复否定同一趋势。

### 3. 分类放宽但入场不放水

识别为通道不代表立即开仓。价格仍必须回到主轨或同源结构区、总分达标、位置优秀并通过执行计划，因此不会因为放宽通道定义就在上轨追多或下轨追空。

### 4. 抓住早期启动

保留显式15分钟研究路径，解决1小时尚未闭合时趋势已经启动但系统完全无候选的问题，同时不让15分钟噪声改写高周期状态。

### 5. 避免小亏频繁离场

0.15ATR只用于接触，0.4ATR继续负责结构失效；普通退出等待1H/4H闭合确认，避免再次恢复ATR短止损。

### 6. 所有不开仓都能解释

方向、总分、位置、计划、资金或系统问题都进入同一可见账本，不再存在后台隐形条件。

## 八、兼容性问题

### 1. 单一行情状态真源

新版本信号和新持仓只能读取market_state_version=4。文档首页列出的版本不是建议值，而是本决策版本的MUST依赖集合；任一版本变化均产生新的不可变decision_version_bundle。

旧消费者必须通过统一适配器读取：

| 新状态 | 旧兼容值 |
|---|---|
| CHANNEL_UP | TREND_LONG |
| CHANNEL_DOWN | TREND_SHORT |
| STRONG_UP | ONE_WAY_UP |
| STRONG_DOWN | ONE_WAY_DOWN |
| RANGE | CHOP |

禁止开仓、加仓、止盈、止损、轮动等消费者自行再次调用旧分类器。所有消费者统一调用market_state_service(version_bundle, as_of)，新仓固定使用v4，旧仓按入场快照中的版本读取；适配器不得把旧仓重新解释成v4。

新持仓保存：

- market_state_at_entry；
- market_state_version；
- channel_id或range_id；
- setup_id；
- entry_pipeline_version；
- channel_geometry_version；
- er12_formula_version；
- score_model_version；
- execution_plan_formula_version；
- position_schema_version；
- decision_reason_schema_version；
- 完整阈值/手续费/滑点/TP权重配置哈希。

旧持仓继续使用其原计划和旧版本，不做在途迁移。部署时若现存持仓缺少decision_version_bundle或market_state_version，统一派生position_version_mode=LEGACY_PRE_V4；该标记只选择冻结的旧持仓管理适配器，不重算止损/止盈、不改变plan_version，也不得因版本缺失停止退出。旧适配器可以继续运行旧算法，但不得把结果写成v4五态。旧历史TREND_LONG/TREND_SHORT只能标记为“旧版趋势映射”，不得伪装成新几何通道并进入新统计。

channel_id和range_id的稳定哈希必须至少包含market_state_version、channel_geometry_version、方向、按时间排序的锚点事件ID和确认时间；不得使用进程内对象地址、集合遍历顺序或当前ATR值。

### 2. 现有setup兼容

新五态只给现有setup增加背景兼容检查，不替代setup自身的：

- 结构来源；
- 建议入场区；
- 失效锚点；
- 目标；
- 优先级；
- 结构事件生命周期。

尤其H4_DESCENDING_RESISTANCE_SHORT等已验证高优先级setup必须保留专项回归测试。

### 3. setup生命周期

setup生命周期只按结构事件定义，新版本不使用TTL或任意分钟冷却：

- 来源结构未失效；
- 建议区未被实体穿越并失去作用；
- 目标未提前触达；
- setup来源事件未被更新结构取代；
- 平仓后必须出现新的独立回踩、反抽、突破回踩或边界收回事件并形成新setup_id，才可再次入场；仅下一根K线到来或更换ID字符串不构成新setup。

旧成交周期若没有setup_id或结构签名，继续使用LEGACY_PRE_V4重入适配器，直到后续出现可确认的新结构事件才切换为新setup_id；既不能因缺签名永久禁止重入，也不能仅在下一根K线立即重开。

加仓、减仓、止盈止损仍归属于同一次开仓生命周期；完全平仓后新setup_id才是新交易。

### 4. 模拟盘风险兼容

继续计算日亏损、周亏损、最大回撤、连续亏损和总风险，但模拟盘默认只提示，不禁止开单。

本PRD适用的实时模拟盘和对应回测固定market_risk_blocks=false：system_risk_state=STRESS及单标的market_context.liquidity_state=THIN继续计算、展示和记录，但不改变AUTO_OPEN_ELIGIBLE或capital_and_order_pass。它们与标的池资格不同：合约不可交易、历史时点成交额/价差未达到池规则仍可在入池前拒绝，并写入pool_evaluation；价格K线过期或不连续仍属于数据阻断。若未来接入真实资金，必须通过新的运行版本显式定义market_risk_blocks=true及可见原因，不能沿用模拟盘decision悄然切换。

默认仍可硬阻断：

- 同标的已有持仓；
- 总持仓容量；
- 可用余额和保证金；
- 固定资本单位；
- 最小订单与精度；
- 服务关闭、数据异常和订单异常。

如果未来显式开启账户亏损类硬限制，必须显示具体阈值和值，不能后台生效。

### 5. 前端和接口兼容

- 不改字段名、列名和布局；
- 行情方向只显示五种中文；
- 风险观察继续放在原因/指标与风险中；
- “否决”栏显示六类中文摘要；
- 新字段仅作为后端兼容扩展，旧客户端忽略即可；
- 精确止损、止盈和R在信号阶段保持空值，开仓后返回最终计划；
- 英文原因必须在后端翻译，不允许前端维护另一套含义。

### 6. 实时与回测兼容

实时和回测必须共用：

- 同一闭合K线分类纯函数；
- 同一结构ID算法；
- 同一评分与setup选择；
- 同一执行计划；
- 同一原因账本投影。

回测额外要求：

- AUTO_TOP50按历史时点成交额和当时已上市合约重建，不能使用当前池；
- 五态每1H更新，执行每15m使用最新闭合快照；
- 限价区只能在decision_effective_at之后触发；实时使用决策落盘后的首笔可执行报价，回测从下一根15m open及其后路径开始；
- 触及判断使用该15m的high/low并采用统一缺口成交规则，不能事后用整根K线最优价；
- 同一时点多个标的先全部评估，再按“评分通道优先级（标准、启动、研究）、总分、现有setup优先级、symbol”稳定排序分配容量；
- 不能按代码循环顺序抢占仓位。

## 九、风险点与控制

### 1. 主轨放宽后把普通方向误叫通道

控制：

- 必须2点建线＋1次后续闭合验证；
- 主轨必须有独立摆动；
- 方向变化超过0.15ATR接触噪声；
- 没有回到主轨附近仍不能开仓；
- 保存channel_shape，区分完整双轨与单边主轨。

### 2. 早期研究假突破增加

控制：

- 只允许4H同向或CLEAN_NEUTRAL，不允许4H反向或CONFLICT_NEUTRAL；
- 闭合15m结构，不使用单根放量或衍生品；
- 研究总分65、真实建议区、结构锚点和执行计划仍必须通过；
- 单独统计1/4/12小时MFE、MAE和失败率。

### 3. ER/D诊断分层跨币种不稳定

控制：

- ER与D仅作为一个推进质量评分与观察组，不是状态或开仓门槛；
- 上线前影子运行；
- 按流动性层级统计，不按单币调参；
- 调整必须提升market_state_version。

### 4. 宽箱体或宽通道带来过大风险

控制：

- 分类阶段不否定结构；
- 当前位置、结构失效距离、最近目标和1.30R在执行阶段审核；
- 固定资本单位不变；
- 不靠缩紧ATR止损解决宽结构。

### 5. 开放空间计划高估收益

控制：

- 只在历史数据中没有可靠对手结构时启用；
- 不生成虚假TP2；
- 1.30R前若存在已知压力/支撑即不能按开放空间通过；
- 到达1.30R只激活保护，不代表必然实现；
- 单独统计开放空间计划的实际R和回撤。

### 6. 新旧状态双脑

控制：

- 单一状态真源；
- 旧接口统一适配；
- 新旧持仓版本隔离；
- 对每个开仓、加仓、退出消费者建立迁移清单。

### 7. 新分类器再次导致长期不开仓

控制：

- 先影子运行，不改变allowed_directions；
- 对比旧系统可交易、新系统不可交易的比例；
- 专门统计被丢弃的H4主轨setup和15m早期研究；
- 未达第七阶段量化发布门前不得切换；
- 保留运行时回退开关。

### 8. 原因很多但仍看不懂

控制：

- 页面按六类合并；
- 只显示当前根因；
- 详细原因保存在决策流水；
- 不把审计字段全部塞入实时信号主对象。

## 十、改动计划

### 第一阶段：冻结基线

- 保存当前代码、配置、评分、setup、持仓管理和原因输出基线；
- 建立FIL、AVAX、TAO、KOMA、1000RATS及镜像空头样本；
- 记录当前每日候选数、进入评分数、达到65/70/75数、开仓数和各层丢失原因。

### 第二阶段：实现纯五态分类器的影子模式

- 只计算并保存market_state_version=4，不改变开仓；
- 实现主轨2＋1验证、可选对侧轨、冻结ID、0.15/0.4双缓冲、可靠箱体和强单边闭合价格结构；
- 检查完整实际窗口连续性；
- 输出与旧方向、旧setup的逐标的差异。

影子期至少统计：

- 旧系统可交易但新系统归为不可交易震荡的比例；
- H4下降压力/上升支撑被丢弃数；
- 突破回踩被丢弃数；
- 15m早期研究被丢弃数；
- 五态覆盖率、持续时间和切换率；
- 强趋势延续率及震荡误判率。

### 第三阶段：统一状态真源

- 建立新状态到旧消费者的唯一适配器；
- 在测试和影子链路中禁止新版本消费者直接调用旧分类器，正式链路此时仍不切换；
- 保存market_state_at_entry和版本；
- 保持旧持仓原计划不变。

### 第四阶段：重排评分和入场流水

- 先生成授权候选区，再计算评分；
- 保留多空双侧诊断；
- 移除单方向多空8分差；
- 移除全部分项最低分和trigger_ready；
- 保留总分、语义结构和位置优秀。

### 第五阶段：接入两阶段执行计划

- 信号阶段只保存结构计划；
- 执行阶段生成结构失效价、灾难保护、有界目标或开放空间计划；
- 最低1.30R只在执行阶段审核；
- 评级、固定单位、账户审核与原子开仓按唯一顺序执行。

### 第六阶段：统一原因账本

- 接入所有return、continue、容量、重入、风险、计划、订单和异常分支；
- 页面只投影六类中文根因；
- 删除英文、泛化和重复原因；
- 保证原子提交前eligible_at_submit=true时必有一次开仓尝试。

### 第七阶段：回测和模拟盘验证

- 实时与回测同快照对账；
- 历史AUTO_TOP50重建；
- 并发候选批量排序；
- 运行新旧策略A/B影子对比；
- v4在本阶段仍只写影子结果，不改变正式allowed_directions、持仓或成交。

发布门必须同时满足：

以下仅决定“新版本是否可以接管”，不是单笔交易条件，不进入评分、策略信号或否决栏。

1. 至少14个连续自然日、5000个价格数据完整的标的决策快照及100个独立setup事件；
2. 冻结回归样本中的现有H4压力/支撑、突破回踩和角色互换setup召回率为100%；
3. 影子样本中，旧系统已满足结构、总分和位置的候选被新系统保留进入计划审核的比例不低于95%；其余每一条必须有人工确认的策略差异，不得因缺少对侧轨、4ATR、9/12、ER/D或EMA五态门槛丢失；
4. 数据完整时五态输出率为100%，页面状态与影子路由状态一致率为100%；
5. 实时/回测同快照状态、setup、区域和计划完全一致；
6. 对五态分层抽样至少200个历史/影子快照，并覆盖每类至少20个；人工结构判定一致率不低于90%；
7. 原子提交前eligible_at_submit=true但没有开仓尝试、decision_universe内未开仓原因空白、重复decision和原子执行副作用均为0。

样本不足时继续影子运行，不能降低发布门换取上线。

### 第八阶段：受控启用与回退

- 全部发布门通过后，才通过运行时决策版本开关让v4接管新的模拟盘decision；
- 首批只切换新决策，不修改正在审核的decision、不迁移已有持仓；
- 回退只影响回退时点之后的新decision；已开仓持仓继续按入场version_bundle管理；
- 观察期继续对照旧链路并保留一键回退；
- 任何P0不变量破坏时立即停止生成新的v4决策。

## 十一、验收标准

### 1. 策略不被误删

- H4下降压力未失效时，合法做空setup仍能进入评分；
- H4上升支撑镜像成立；
- 突破回踩和真实支撑压力仍有专项测试；OI洼地在H4看多后的参与流增强、高位派发与bearish价格结构绑定也有专项测试，且二者不能独立创建方向或区域；
- 缺少对侧轨不得单独取消有效主轨方向；
- CLEAN_NEUTRAL和日线未确认不得阻断启动/研究通道；CONFLICT_NEUTRAL必须展示双方冲突结构；
- RANGE且range_tradeable=false时，合法15m早期研究候选仍可见且可在模拟盘执行；它不能因表外路由被丢弃；
- CLEAN_NEUTRAL下多空15m早研同时成立时不按分数或遍历顺序选边，微结构冲突原因可见；
- 1H/4H EMA20、EMA60和BOLL主区分别保留，区域之间不得桥接；
- H1_PULLBACK的VWAP、MA20及EMA/BOLL独立区和1H闭合hold/reject均有多空镜像回归；KC只保持评分/质量角色；
- 除H4上升支撑多头的镜像effective priority=100外，现有setup_id基础优先级顺序保持不变，新五态类别不得覆盖它；
- 未触价高优先区不得遮挡已触价且计划通过的其他合法区；
- 4H与五态冲突时严格按权威路由表处理，不存在第二次方向审核。

### 2. 五态正确

- 上涨2点主下轨＋后续闭合验证成立后输出通道上涨；
- 下跌完全镜像；
- 对侧轨不足时仍是PRIMARY_RAIL_TREND，不是自动震荡；
- 高ER/D但仍被可靠双轨容纳时保持通道；
- 闭合结构突破或成熟单向摆动成立、未被镜像结构破坏且不受箱体/配对通道容纳时输出强单边；
- 可靠箱体内的微型通道不覆盖震荡；
- 数据异常不输出震荡；
- 每个有效快照只能有一个五态。
- 对一组价格序列执行符号镜像后，market_state、候选方向、区域、结构失效、目标顺序、R和成交结果必须完全镜像；只有手续费和取整造成的可解释最小差异例外。

### 3. 不存在重复门槛

- 位置、触发、推进和结构分均无独立最低值；
- 单方向候选不要求多空8分差；
- 4H反向只审核一次；
- 衍生品缺失不封顶、不阻断；
- 当前价进入授权区且setup有效时位置必为优秀；
- 新主轨/箱体边界区按冻结轨道、冻结0.15ATR缓冲和公开公式唯一生成，实时与回测上下界完全一致；
- 已授权1H/4H区域不再要求通用15m触发。
- 突破回踩、假突破收回和15m战术setup的固有闭合确认仍必须存在，且不会被误当成通用trigger_ready。

### 4. 交易计划正确

- 信号阶段无精确止损/目标/R时信号仍可存在；
- 没有结构失效锚点不能创建持仓，且原因可见；
- 0.15ATR不触发普通结构退出；
- 1H/4H闭合结构失效按0.4ATR缓冲执行；
- 有界目标按最近对手结构选择；
- 价格发现可使用OPEN_SPACE且不虚构TP2；
- OPEN_SPACE持仓可用空TP字段完成开仓、保存、重启恢复和结构退出，任何消费者都不会补默认TP或把P_1_30R当作TP；
- OPEN_SPACE可携带空TP通过PortfolioRiskGate/TradePlan校验，账户风险仍按结构止损计算；
- OPEN_SPACE达到P_1_30R只进入PROTECTION_ELIGIBLE；没有新闭合1H保护摆动时不得生成任意保本硬止损；
- 净计划R低于1.30R时保留信号、拒绝本次执行并显示实际值。

### 5. 可审计与原子性

~~~text
原子提交前eligible_at_submit=true的决策数 = 自动开仓尝试数
符合条件但未尝试开仓数 = 0
未开仓且否决摘要为空数 = 0
同一decision_id重复开仓尝试数 = 0
新版本出现旧四项分项最低分原因数 = 0
页面market_state与路由market_state不一致数 = 0
执行失败但余额、手续费、持仓或成交发生变化数 = 0
~~~

### 6. 回测一致性

- 同一数据截止时间的实时与回测五态、4H背景、setup、评分、入场区和计划一致；
- 同一as_of下把现有interval选择器分别设为15m、1h、4h、1d，自动decision结果完全一致；只有展示取样可变化；
- 不读取未闭合1H/4H或未来枢轴；
- 历史标的池不使用当前TOP50；
- Top80影子评分与Top50自动决策分母严格分离，池排名原因可重放；
- 实时首笔可执行报价与回测下一根15m open遵循同一decision_effective_at语义，不使用决策K线high/low；
- 同时多个候选不因遍历顺序改变开仓结果；
- 无version_bundle的旧持仓稳定进入LEGACY_PRE_V4管理并能正常退出，重启后行为一致；
- 服务重启和完整重放产生相同结构ID与状态。

## 十二、下次优化建议

本版落地前不再添加新指标。后续只基于样本研究：

1. ER_TR12和D12的联合推进质量是否需要按流动性分层；
2. 15m早期研究的1/4/12小时延续率和失败率；
3. PRIMARY_RAIL_TREND与PAIRED_GEOMETRIC_CHANNEL的胜率、实现R和主轨失效率；
4. 开放空间计划与有界目标计划的实际R差异；
5. 1.30R是否仍适合各类setup；
6. 哪些现有评分项长期无区分度，可做进一步减法。

任何后续优化必须先回答：

- 它是否描述了新的独立市场事实；
- 现有证据族是否已经表达同一事实；
- 它是评分、路由、执行计划还是风险提示；
- 它会不会形成页面看不见的额外门槛。

不能回答清楚的参数，不进入策略。
